# 阅读资料、离线阅读与辅助搜索更新

本轮以现有 0.1.6 为基础，完善阅读资料恢复、连续阅读、同步追更与网络小说搜索。保留工作区原有的章节末尾上滑、页码常显和工具栏行为。

## 阅读资料备份与恢复

入口为「我的 → 阅读资料备份」，也可从「阅读与外观 → 备份与恢复阅读资料」进入。

- 导出 ZIP 包，包含书架与收藏夹、阅读进度、书签笔记、单书偏好、文库挂载关系与分卷排序、个人术语、搜索记录、标签原文及自定义译名等资料。
- 本地小说的解析正文和插图始终包含；可选择额外打包原始 EPUB/TXT/SRT。没有原件的旧资料仍可恢复阅读。
- 不包含登录会话、Cookie、访问令牌、待同步操作、下载任务或可重新生成的网络正文缓存。
- 恢复前检查格式版本、路径、文件大小、SHA-256 和文档关联，随后显示资料数量与缺失原文统计，再由用户确认合并。
- 合并时保留本机已有的书籍整理和已编辑译名，阅读进度取更新时间较新的记录。新安装还会恢复全局偏好；已有资料的设备保留本机全局偏好。重复恢复不会重复添加相同的本地正文。
- 文件使用独立 ID 写入，确认完整后原子提交资料索引。提交前失败会回滚本次新文件；原有资料不会被覆盖或删除。标签词典单独保存失败时明确提示部分成功，可保留备份重试。
- 本地资料库损坏时进入保护页面，保留原文件，提供最后良好副本或外部备份恢复；不会把读取异常当成第一次安装而静默写入空库。

当前备份限制为解压总量 1 GiB、单文件 128 MiB、索引 16 MiB、最多 30,000 个条目。导出和恢复均执行大小校验；超限会明确报错。

## 连续阅读与离线正文

- 网络小说详情页的继续阅读入口显示「第几章 · 章节名」。本机与原站进度冲突时也显示可读章名；目录中的分组标题不计入章序。
- 默认在前台阅读时预读后 3 章且仅使用 Wi-Fi；阅读偏好可设关闭、1/3/5 章，并单独调整网络条件。请求绑定当前会话，离开前台、退出阅读或清理缓存后停止对应预读。
- 目录可选择起止章节进行手动缓存，每批最多 200 章，显示进度并可取消；缓存继续遵循原有 256 MiB 淘汰预算，并不等同于永久保存的本地文件。
- 阅读器保留本章查找，并增加「整本搜索（本地 / 已缓存章节）」。本地文件搜索全文；网络小说只检查本账号已有目录快照及已缓存正文，不为搜索自动下载全书。缺少离线目录时明确说明仅能搜索当前章。
- 搜索显示实际覆盖范围、章节与段落片段，点击结果跳转到相应位置。单次最多返回 200 个匹配段落，并限制扫描字符总量，支持取消。
- 文库挂载分卷读完后，可按书架中保存的分卷顺序进入下一卷；自动分页末页也可使用下一分卷入口。
- 检测到书籍译文补齐时，可提示刷新缓存正文并恢复阅读锚点。章节抓取时间使用独立索引，避免把缓存的最近访问时间误判为译文更新时间。

## 自动同步与追更

- 「我的 → 同步状态」展示当前账号的待同步操作、最近尝试、最近成功、错误原因与手动重试入口。
- 默认开启联网自动同步，使用网络约束及退避重试，并有后台补偿检查。系统调度可能延后，不承诺即时后台执行。
- 自动同步只处理当前账号的幂等收藏和阅读进度。发帖、评论不进入自动重发队列；切换账号或退出后，旧会话不能借用新账号继续请求。
- 网络错误、429 和暂时服务错误会保留操作并重试；权限或资源错误会显示原因，等待用户处理，不阻塞其他独立作品。重新登录或手动重试可继续处理待同步记录。
- 「书架更新」按作品展示新增章节、各翻译引擎补齐章节数、新增分卷文件，支持标记已读。通知参考单书或全局首选译文引擎；仅阅读日文时不提示纯译文补齐，新增原文章节和分卷仍会提示。
- 老版本没有分引擎计数的书籍，以及尚无分卷明细的文库条目，会先建立基线，避免把历史译文或已有分卷全部误报为新增。原站进度仍为章节粒度，本机继续保存段落及字符偏移。

## 网络小说辅助搜索与标签词典

在「发现 → 网络小说」展开「辅助搜索」，可填写全部包含、任意包含、精确短语、排除关键词和章节数上下限，并预览生成的原站表达式。

辅助条件默认追加到搜索框，保留手工表达式；替换现有内容需要明确确认。相同标签不会重复追加；与手工条件相反时提示先调整条件。

- 内置少量来自原站日中映射的常用标签，按题材、人物、情节分类。
- 正常加载网络小说列表、详情、云端收藏和历史等响应时，从已有 `keywords` 中积累候选；不额外请求全站标签。
- 原文和中文翻译均可联想，优先按匹配程度、最近使用和常用程度排序；没有候选时可手工添加标签原文。
- 标签统一显示为 `原文 (中文翻译)`；翻译为空时只显示原文。读者可编辑或清空中文译名，后续浏览不会覆盖自行编辑的内容。
- 每个标签可选择包含或排除，例如包含病娇、排除后宫生成 `ヤンデレ$ -ハーレム$`。搜索始终使用原文，中文译名仅用于显示与联想。
- 原文和译名各最多 256 字符；词典最多保留 20,000 项，优先保留已编辑、最近使用与内置常用标签。存储失败会提示并重试。

语法依据原站使用教程与本地参考源码的服务端解析实现；章节数 `>n` / `<n` 是严格大于 / 小于，不包含边界。参考：[原站使用教程](https://n.novelia.cc/forum/64f3d63f794cbb1321145c07)。
