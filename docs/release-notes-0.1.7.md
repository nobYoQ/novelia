9.19 : 更新版本为0.1.7

**阅读器**

- 网络小说详情页的「继续阅读」显示具体章序和章节名，本机与云端进度不一致时也能直接辨认章节。
- 连续滚动到本章末尾后，继续向上滑动一段距离并松手，即可进入下一章。
- 自动分页底部常显「当前页／本章总页数」和本章百分比，收起工具栏或关闭翻页按钮后仍可查看。
- 文库挂载分卷读完后，可按保存的分卷顺序继续阅读下一卷。
- 检测到新的译文时提示刷新本章，刷新后恢复阅读位置。

**离线阅读**

- 新增后续章节自动预读，默认仅在 Wi-Fi 下预读后 3 章；可选择关闭或预读 1／3／5 章。
- 支持选择起止章节进行缓存，每批最多 200 章，可查看进度并随时取消。
- 新增整本搜索：本地小说搜索全文，网络小说搜索已缓存章节；显示搜索覆盖范围，点击结果跳转到对应章节和段落。

**搜索与标签**

- 网络小说新增可折叠的辅助搜索面板，支持全部包含、任意包含、精确短语、排除关键词和章节数范围，自动生成原站搜索语法。
- 应用辅助条件时保留搜索框中的手工表达式，替换前提供确认，并检查相反的标签条件。
- 内置题材、人物、情节等常用标签；正常浏览列表、详情和云端书架时积累标签，无需额外请求全站标签。
- 支持标签原文和中文联想，找不到候选时仍可手动添加；每个标签可选择「包含／排除」。
- 标签显示为「原文 (中文翻译)」，支持编辑或清空中文译名；搜索使用原文，自定义译名随阅读资料备份保存。

**备份与恢复**

- 新增完整阅读资料 ZIP 备份，包含书架、收藏夹、进度、笔记、阅读偏好、分卷关系与排序、个人术语和标签译名。
- 备份包含本地小说正文与插图，可选同时打包原始 EPUB／TXT／SRT；没有原件也能恢复阅读。
- 恢复前检查备份并显示预览，合并时保留本机已有整理与自定义译名，阅读进度取较新记录，重复恢复不会重复添加相同正文。
- 本地资料库损坏时保护原文件，支持恢复最后良好副本或外部备份。入口位于「我的 → 阅读资料备份」。

**同步与追更**

- 新增联网自动同步，离线收藏和阅读进度保留在待同步队列，网络恢复后自动重试。
- 「我的 → 同步状态」可查看待同步操作、最近同步结果和失败原因，支持手动重试或移除操作。
- 离线收藏显示「等待同步」，服务器确认成功后才显示完成；切换账号后仅处理当前账号的操作。
- 新增「书架更新」，分别显示新增章节、GPT／Sakura／有道译文补齐和新增分卷文件，支持标记已读；通知参考首选译文引擎，仅阅读日文时不提示纯译文补齐。
