# 交互、阅读、性能与动效更新

当前版本保留 Material 3、纸张主题、小绿贴纸、电子纸交互和账号隔离，以及本轮的交互、阅读、性能和动效优化。2026-09-20 按用户要求取消 OCR，相关页面、下载器、模型及原生引擎已移除。后续已补齐进度表中的交互与动效剩余项，最新说明与安装包见 [交互与动效补全](interaction-motion-completion.md)。下方 OCR 及移除记录保留用于追溯。

本页记录已经交付的实现与验证，不表示最初分析中的所有建议均已完成。交互、性能、动效的逐项状态及剩余验收条件见 [优化进度清单](optimization-progress.md)。

## 阅读与操作

- 搜索保留语言段和字符范围，支持同段多处命中、前后查找、双模式高亮及跨章跳转。
- 统一连续滚动与自动分页的字重和主辅文字规格，正文准备与繁简处理支持取消。
- 阅读设置将常用项前置并分组；普通屏自动分页加入可中断短过渡，电子纸和减少动效仍即时切换。
- 插图失败可重试；朗读改为句级队列，暂停后恢复最多重读当前句。
- 下载按登录、暂停、失败等状态提供动作；导入后进入阅读，导出与删除等放入次级入口。
- 云端收藏登录后续接操作，可直接新建收藏夹；离线取消收藏显示待处理状态并允许撤销。
- 本地文件删除确认，书架移除和笔记删除支持撤销。笔记增加书名、章节和搜索/按书筛选。
- 发现页普通筛选显示摘要、清空和放宽条件入口；已知社区权限限制提前说明并保留草稿。
- 默认封面采用稳定的多组配色；宽屏书籍详情采用简介与目录双栏。
- 共用 AppSheet 遵循电子纸与减少动效模式；统一动效时长，避免初次内容与导航重复淡入。后续已完成面板、对话框和菜单审计及静态显示适配，范围见 [交互与动效补全](interaction-motion-completion.md)。

## 数据与兼容

- 本地书采用小目录与内容寻址的章节文件，按章读取；旧书首次读取时原子迁移，空间不足时保留旧格式读取能力。
- 文章和草稿正文从高频状态快照中拆开，减少进度变化时的重复编码与落盘。
- 阅读进度、笔记和书库元数据目前仍共用较小的状态快照，尚未完成高频进度的独立持久化。
- 备份仍导出自包含 v1 格式，恢复不依赖原设备的章节索引；保留损坏恢复和最后有效快照。
- 阅读、预读和离线批量缓存共用同章请求；按账号和缓存代次隔离，最后一个订阅者离开时取消请求。
- 详情缓存使用增量体积统计；非首屏词库整理延后；会话刷新支持协程取消。

## 已取消的 OCR 功能

本地图片识字和按需下载均已取消。升级启动时清理旧模型，保留校对草稿与已导入书籍；旧草稿可在普通文件工具中取回。详见 [取消与升级说明](local-ocr.md)。

## 性能验证

新增独立 `benchmark` 模块，使用 Macrobenchmark 测量冷启动和 UI 帧时间，并提供 Baseline Profile 生成器。性能场景测试使用独立临时资料库测量千本书架、万章目录和超长正文，避免污染实际书架。

普通功能测试、模拟器性能场景和真实设备跑分具有不同用途。模拟器运行能验证基准代码及功能，不能据此宣称低端手机帧率、耗电或启动速度的改善百分比。

连接测试设备后，可使用：

```powershell
./build.ps1 -Tasks @(':app:generateReleaseBaselineProfile')
./build.ps1 -Tasks @(':benchmark:connectedBenchmarkReleaseAndroidTest')
```

Baseline Profile 应在变更主要用户路径后重新生成。Macrobenchmark 建议使用物理设备和 Release 派生构建；记录设备、系统、温度和编译模式，用同一数据规模比较改动前后。特别关注首次可阅读时间、重排耗时、卡顿帧、内存与磁盘写入。

## 历史：按需模型版本（2026-09-20，已撤回）

- 默认 APK 保留本地识字入口和原生推理引擎，不携带模型。进入页面或选择图片不会触发下载；用户点击下载后获取约 21.5 MB 官方模型，安装完成后可离线识别。
- 模型下载显示进度，可取消和重新下载；固定归档与模型文件分别校验大小 / SHA-256，受限解包后原子安装。中断或损坏下载不会替换原模型；系统终止应用遗留的临时文件会在下次下载前清理。
- 模型文件位于应用私有非备份目录。识别会话持有模型使用权，释放原生引擎后才允许删除；删除模型保留校对草稿和书架内容。
- 文件加载接口直接交给 ONNX Runtime 本地路径，避免先复制完整模型到 Java 字节数组。原有 assets 接口保留兼容用途；真实模型样本只进入测试 APK。
- 新增 13 项模型管理单测，覆盖正常下载、下载取消、长度 / 哈希异常、危险归档、识别与删除并发、损坏检测、原子替换及孤儿临时文件清理。最终 240 项 Release JVM 单测全部通过。
- Debug 构建、测试 APK 和 Debug Lint 通过；最终 ARM64 Release 构建与 Release Lint 通过。
- API 35 / x86_64 模拟器上的 6 项设备回归通过，覆盖真实中文 / 英文识别、无模型时的下载入口、删除确认与草稿保留、键盘编辑及减少动效。另 1 项联网专项完成真实官方模型下载、校验和本地引擎加载；初次因测试设备网络关闭失败，开启测试网络后通过，完成后恢复原设置并关闭模拟器。
- 新的 ARM64 包约 59.3 MB，较上一轮 77.9 MB 减少约 18.6 MB（24%）。模型在旧 APK 内经过压缩，因此安装包减少量小于解包后的 21.5 MB。下载模型后的数据占用会另加约 21.5 MB；原生库约 44.2 MB 仍包含在基础包中。
