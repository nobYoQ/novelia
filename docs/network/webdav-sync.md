# WebDAV 多设备同步

[返回网络索引](README.md) · [设置与笔记](../features/settings-and-notes.md)

入口为“设置 → WebDAV 多设备同步”。主页面以分组卡片展示服务器、七类同步开关、自动同步和状态，开关修改立即保存。“同步服务器”进入独立连接页面，填写 HTTPS 服务地址、用户名、密码或应用授权码后点击“保存并测试”；相对目录与设备名称位于“更多选项”。返回主页面后，点击底部按钮查看同步预览，再选择首次设置以本机或远端为准并加入。已有资料按记录合并；新设备的空集合不会删除远端记录。改变服务地址、账号或目录会解除旧绑定并清除旧密码，需要重新填写和确认。

## 可选范围

七个类型分别使用独立开关、文件和成功状态。关闭某项后，不读取、上传或应用该项；设备已有数据和服务器已有文件仍保留。重新打开后继续合并离线期间的修改；此前没有加入的类型需要再次预览并合并。

| 类型 | 同步内容 |
| --- | --- |
| 本地设置 | 可迁移的界面与阅读偏好、网络书籍的单书设置、屏蔽列表 |
| 标签库 | 标签原文、译名、分类、空分类、分类顺序和使用记录 |
| 本地收藏 | 网络书籍摘要、收藏夹、收藏归属和排序 |
| 阅读进度 | 网络书籍的章节、原文段落、内容指纹和阅读时间 |
| 书签 | 网络书籍的书签位置、摘录和标题快照 |
| 笔记 | 网络书籍的笔记正文、位置、摘录和标题快照 |
| 阅读历史 | 网络书籍最近阅读章节、书名和时间；独立于阅读进度 |

所有类型均排除本地文档、导入文件、本地分卷及这些书籍的进度、历史、书签、笔记和单书设置。正文、封面字节、下载成品、缓存、草稿、登录资料、原站待办及 WebDAV 凭据不进入同步载荷。网络收藏只携带书籍摘要，不下载小说文件；原站云端收藏/历史上报仍通过原来的独立同步入口处理。

亮度、电子纸及翻页等设备偏好默认不参与，可在设置项下另外开启。电子纸等相互关联的字段作为完整组同步，避免组合出不合法的状态。首次开启该子项需要再次预览并合并，选择设置来源。关闭子项不会删除服务器上已有的设备偏好。

## 多设备与冲突

实现位于 [data/webdav](../../app/src/main/java/cc/novelia/app/data/webdav)。`SyncReplica` 的设备身份、时钟和记录版本与业务快照一起原子保存；`KeywordStore` 保存独立的标签版本。收藏夹与标签分类使用稳定 ID，重命名不改变身份。普通备份和标签导出移除同步身份、版本和任务，恢复到其他设备不会复制设备身份。

合并使用设备计数器与因果版本向量，不以设备真实时钟决定修改胜负。各记录的不同字段可以并行合并，屏蔽集合逐成员合并。普通字段存在并发版本时使用确定性的选择，仍保留候选以确保三设备合并顺序一致。删除保留墓碑，并发删除优先；观察删除后的显式重新添加产生新版本。墓碑目前不自动清理，长期离线设备不会因墓碑过期恢复已删记录。

首次设置来源选择只影响设置偏好，屏蔽列表始终合并。默认标签译名和默认分类不能覆盖用户编辑，包括用户明确清空的译名。合并期间继续编辑的本地字段会重新应用到本次结果中，不覆盖同记录其他已合并字段。

进度的章节和段落是一个完整锚点，避免分别取两个设备的值。不同布局恢复使用原文段落；不同译源、正文变化或原段落消失时清除像素和字符偏移。并发进度保留本机阅读位置，界面提供全部候选；笔记正文并发编辑同样保留候选，支持展开完整文字并选择版本。选择会生成观察了所有候选的新版本，再同步至其他设备。

## 条件提交与故障保护

同步目录包含 `manifest.json`（协议版本和数据集 ID）以及七个 JSON 文件。已连接目录的 manifest 或已同步数据文件消失时停止该项，不把本机快照当成新文件重建。切换数据集清除旧缓存和加入基线；未知协议、数据集不匹配、非法记录、本地文件引用、超限或损坏载荷均拒绝落地。

网络传输使用独立 OkHttp 客户端，不共享原站 Cookie、认证头、拦截器或 ECH。只接受 HTTPS；重定向只允许同源同路径的规范化，不携带凭据跨站。密码由 Android Keystore 对应的独立 `DeviceCipher` 保存，不写入日志、备份、同步 JSON 或 WorkManager 参数。

服务必须支持强 ETag 和条件写入：创建使用 `If-None-Match: *`，更新使用 `If-Match`。测试连接在唯一临时文件上验证读写、拒绝重复创建、版本变化和拒绝旧版本更新，再清理该测试文件。412 时重新读取并合并，单次最多尝试四轮，不降级为无条件覆盖。规则依据 [RFC 9110 条件请求](https://www.rfc-editor.org/rfc/rfc9110.html#name-if-match) 和 [RFC 4918 WebDAV 实体标记](https://www.rfc-editor.org/rfc/rfc4918.html#section-8.6)。

每次上传先等待捕获操作和逻辑时钟持久化；初始化选择产生的新计数器也先预约并落盘。上传成功后再应用业务值和确认缓存；上传过程中更改配置或停用同步会阻止旧结果落地。重复执行保持幂等。七个文件分别提交，部分成功会保留成功结果，失败类型可单独重试。

每个远端响应上限为 16 MiB；载荷须是合法 UTF-8，容器深度最多 64。协议另限制记录、设备、字段与并发候选数量。本机书库或标签库损坏时保护原文件并阻止受影响同步；同步缓存损坏时要求重新预览确认。服务返回认证、权限、容量或格式错误时显示原因，网络、服务端和并发故障采用退避重试。

## 自动同步

- 应用进入前台时同步，此后前台每三分钟检查远端。
- 本地修改后先落盘，合并一次性任务；前台约十秒后同步，连续翻页不会无限推迟首次提交。
- 后台由 WorkManager 按 15/30/60/360 分钟检查，默认 30 分钟，网络约束默认非计费网络。
- 底部“立即同步”可在自动同步关闭时运行；关闭“启用 WebDAV”取消自动任务并使当前配置代次失效，进行中的同步也可通过此开关停用。取消最后一个同步项会同时停用同步。

后台执行受 Android 电量、网络和进程限制，周期为检查间隔，不保证精确执行时刻。离线操作持久保留，恢复网络后继续合并；系统杀死应用后由持久任务兜底。主页面展示最近成功和错误，展开“查看详细状态”可查看各类型的成功时间、待提交记录数和错误；需要选择的冲突单独展示。

## 验证

纯 JVM 测试覆盖三设备合并、删除/重新添加、独立类型开关、默认标签保护、设置来源、同步期间编辑、本地文件排除、定位回退、412 重试、配置代次变化、文件消失及上传前落盘失败。MockWebServer 验证条件请求、强 ETag、探测读回、路径编码、凭据隔离和重定向限制。测试入口为 [WebDavMergeTest](../../app/src/test/java/cc/novelia/app/data/webdav/WebDavMergeTest.kt)、[WebDavProjectionTest](../../app/src/test/java/cc/novelia/app/data/webdav/WebDavProjectionTest.kt)、[WebDavExchangeTest](../../app/src/test/java/cc/novelia/app/data/webdav/WebDavExchangeTest.kt)、[WebDavClientTest](../../app/src/test/java/cc/novelia/app/data/webdav/WebDavClientTest.kt) 和 [WebDavPayloadTest](../../app/src/test/java/cc/novelia/app/data/webdav/WebDavPayloadTest.kt)。

[WebDavLayoutTest](../../app/src/androidTest/java/cc/novelia/app/ui/settings/WebDavLayoutTest.kt) 使用虚拟配置离线检查深浅色界面、独立同步开关、运行中停用、密码显隐、高级配置与大字体下的操作可达性，并生成主页面和服务器页面截图。界面测试不使用真实账号或设备保存的凭据。

真实服务兼容性、Keystore、设备休眠及后台限制仍需在 Android 设备与实际服务上验证。
