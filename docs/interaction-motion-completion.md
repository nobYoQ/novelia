本轮按 [优化进度清单](optimization-progress.md) 的剩余范围补齐 I06、I11、I12、M03、M04、M06，继续使用不含 OCR 的轻量构建。

上述实现已随 0.1.8 发布，最新安装包及升版验证见 [0.1.8 发布复验](release-0.1.8-verification.md)，面向用户的说明见 [0.1.8 更新记录](release-notes-0.1.8.md)。下方保留升版前的交付记录。

## 书目同步反馈

书架、发现、云端收藏、阅读历史等共用书目行显示当前账号的待同步、正在同步、失败和需要重新登录状态，同时说明收藏、取消收藏或阅读进度操作。行内可重试本书，不会顺带提交其他书籍；已有取消收藏撤销入口继续可用。

正在同步的标识只存于内存，请求结束或取消后立即清除。等待同步锁前固定账号与登录代次，切换账号、退出后重新登录均会使旧任务和旧移除确认失效；已完成或被新操作替代的失败记录及时清理。

## 大屏书架与阅读

- **书架＋详情**：内容区域达到 840dp 时并排显示，左侧选择、右侧查看简介和目录。选择状态、书架位置及每本书的详情状态可跨宽窄切换与界面重建恢复；阅读返回后仍在原详情中。窄屏本地书继续支持直接进入阅读。
- **目录＋正文**：阅读区域达到 840dp 时常驻目录，支持搜索、正倒序、当前章标记及定位。目录状态和正文字符位置在宽窄切换时保留，选章后继续显示当前筛选。

## 筛选与章节切换

云端收藏和辅助搜索的筛选面板展开、收起时，列表会补偿面板高度变化，保持长列表中所看书目在屏幕上的位置。补偿不取消正在进行的滚动，也不会再次触发自动收起；面板中的编辑和滚动位置会保留。到达列表边界时仍遵守正常滚动范围。

拖动章节末尾或选择另一章后，先加载目标章节，再离开当前正文。加载期间可取消；失败时保留当前章与阅读位置，提供重试及继续阅读。重复触发与取消后迟到的响应不会误切章；成功切页使用已加载的正文，不重复请求，并重新核对账号会话和缓存代次。

## 面板与动效策略

应用自定义的筛选、列表、阅读覆盖层和页面过渡统一使用公共动效参数；普通弹层沿用 Material 原生行为，并统一接入减少动效策略。减少动效或电子纸模式下，共用面板、菜单、提示及加载反馈走静态显示，对话框禁用系统窗口动画；内置网页同步关闭 CSS 动画、过渡和平滑滚动。系统动画时长比例设为 0 时也切换到静态策略。

直接拖动、捏合以及反映真实进度的确定值进度条仍提供操作反馈；电子纸继续使用已有的分屏和按钮操作。实现使用当前依赖的公开 API，没有引入新的动画库。

## 验证与安装包

- JVM 单元测试：246 项通过，无失败或错误，覆盖单书同步、账号与登录代次隔离、章节加载取消及失败恢复等。
- Android 15 / API 35 模拟器：73 项独立功能用例通过，包含手机尺寸与 1200 × 900dp 大屏尺寸；复测同一用例只计一次。覆盖双栏状态恢复、选中本地书的移出和删除、目录筛选延续、正文位置、同步行内重试、筛选补偿、静态弹层及网页动效。
- 系统关闭动画的像素稳定性用例在 `animator_duration_scale=0` 下单独通过，测试后恢复原设置；未将默认环境中的跳过计为通过。
- Debug、设备测试包、NonMinifiedRelease 和 ARM64 Release 构建通过，Debug / Release Lint 通过。
- 已重新采集启动及书架 / 设置导航的 Baseline Profile，生成任务通过，配置随 Release 打包。
