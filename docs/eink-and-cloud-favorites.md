# 电子纸阅读与云端收藏

## 电子纸阅读

在阅读器「阅读设置」或「我的 → 阅读与外观」中开启「电子纸阅读模式」，可沿用全局设置或仅应用于当前小说。

- 保留当前应用色调和所选阅读主题，按屏幕可用空间和完整文字行分页。长段落可跨页，插图独立占页并缩放适配。「阅读主题」包含跟随应用、纸张、浅色、深色、黑白五个互斥选项；选择「黑白」时阅读器使用白底黑字，选择其他主题立即切换。旧版已开启的黑白色调设置对应「黑白」主题。
- 浅色阅读主题使用淡绿色正文背景，与白底黑字的黑白主题区分。各主题的工具栏采用比正文稍深的同色系背景，并沿用工具栏透明度设置。阅读配色只作用于正文及阅读工具栏，阅读偏好、目录和其他设置面板由 App 主题管理，黑白主题不会将设置面板改成黑白。
- 正文不拖动、不惯性滚动；滑动手势松开后切换一整页。阅读工具栏、章节切换、正文加载与设置面板不使用过渡动画。
- 「分页模式」提供「连续滚动」和「自动分页」：前者整章连续排列、上下滚动浏览，后者按屏幕大小提前排成独立页面。「滚动翻页」和「左右翻页」仅在自动分页下显示，分别控制上下、左右滑动，不再决定分页模式。
- 「显示翻页按钮」在两种模式中始终可设置。连续滚动时显示上一屏、下一屏；自动分页时显示上一页、下一页和页码。关闭后隐藏对应按钮，不改变分页模式；自动分页到章节末继续向后翻进入下一章，章节首向前翻进入上一章末页。
- 阅读工具栏以半透明背景覆盖正文。两种分页模式均使用固定正文区域，工具栏显隐、搜索栏展开、翻页按钮显隐和透明度变化不再调整正文空间。「工具栏透明度」位于阅读偏好中，默认 25%，可在 0%（背景不透明）至 100%（背景完全透明）间调整；文字和图标不随此设置变淡。全局、单书设置和备份均会保存该值。
- 首次开启电子纸模式时，保存当前分页模式、两种手势、翻页按钮和音量键设置，再启用自动分页及这些翻页操作。关闭时恢复开启前的设置，并记住本次电子纸设置；再次开启沿用上次电子纸设置。主题、字号等其他偏好不受切换影响。
- 两套翻页状态保存在阅读偏好中，重启、普通设置备份和单书设置均可保留。旧版本已经开启电子纸模式、但没有保存开启前状态时，首次关闭回到连续滚动和原始翻页默认值；旧版明确开启的翻页按钮继续保留。
- 支持 Page Up / Page Down、方向键、空格，以及映射为这些标准 Android 按键的翻页器。启用模式时同时开启音量键翻页，可在阅读偏好中单独关闭；其他厂商私有按键码未做映射。
- 长按文字仍可选择、分享和添加笔记；保留章节搜索、目录、缓存刷新和系统朗读。
- 保存段落与段内文字偏移；旋转屏幕、改变字号或可用空间时重新分页，并定位到包含原位置的页。关闭静态分页后回到对应段落的流式阅读。
- 本功能不调用特定电子纸厂商的全刷／局刷接口，设备刷新策略由系统控制。

## 全应用电子纸交互

- 「我的 → 阅读与外观」提供直接开关，与默认阅读偏好中的电子纸模式同步。单书覆盖不改变书架及其他页面的交互。
- 原生列表、长表单、目录及管理面板在手指滑动期间保持静止，松手后无动画跳转约一屏，保留少量重叠内容以便接续阅读；取消手势不翻屏，不产生惯性或边缘拉伸。可滚动区域提供上一屏／下一屏按钮，横向筛选也按屏切换。
- 弹出面板在电子纸模式下使用带关闭按钮的固定面板。分卷排序改为直接显示上移、下移按钮，沿用每本文库保存的顺序；阅读数值使用加减按钮，插图使用缩放及方向按钮。关闭模式后恢复普通滚动、滑块和拖拽，不改变已保存的数值及排序。
- 原站内置网页使用松手后按屏滚动，保留链接点击；禁用页面 CSS 平滑滚动、过渡和动画。跨域认证页面保留浏览器原生输入和滚动，以便登录表单正常使用；系统文件选择器、外部浏览器及设备刷新策略仍由系统控制。
- `AppPagingTest` 覆盖手指按住时不移动、松手仅一屏、无惯性、取消手势、横纵手势分流、表单及面板；`WenkuVolumeFlowTest` 覆盖全局开关、上下按钮排序、重启持久化及关闭后的拖拽恢复。

## 云端收藏

- 网络与文库分别在收藏夹多于一个时显示「全部收藏」，直接使用服务器 `all` 查询，排序和分页覆盖全部结果。
- 网络收藏支持搜索中／日标题或作者、六个书源多选和反选、连载状态、一般向／R18 分级、GPT／Sakura 译文、更新时间／收藏时间排序。改变条件回到第一页，重置恢复默认条件。
- 空书源选择保留为空，按原站行为显示无匹配结果。
- 文库收藏接口仅提供排序，没有网络小说的这些筛选参数。
- 「全部收藏」不显示重命名和删除收藏夹操作；默认收藏夹不显示删除操作。取消某本小说的收藏沿用原站按账号和小说删除的语义。
- 筛选区限制高度并可单独滚动，避免较小屏幕无法访问列表；摘要条一直保留。默认向下浏览列表超过一定距离后以约 0.3 秒的收缩、淡出动画折叠，箭头同步转动，点击摘要平滑展开。「滚动时自动收起筛选」开关位于「我的 → 阅读与外观」，保存在本机并随普通设置备份导出。减少动态效果或全局电子纸模式下立即折叠，不播放动画；动画途中开启减少动态效果也立即到达最终状态。
