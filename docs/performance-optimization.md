# 性能、缓存与动效优化

本轮针对代码中确认的主线程写盘、重复解码、无界缓存、请求取消和刷新状态问题进行优化，保留现有 Material 3 视觉风格及数据格式。未以模拟器结果推断真实设备的帧率、耗电或启动时间提升。

## 主要变化

| 范围 | 实现与预期作用 |
| --- | --- |
| 启动 | 在应用 IO 协程初始化本地库和会话，界面等待初始化完成后使用数据，避免以空状态覆盖既有资料。 |
| 导航与主题 | UI 操作明确在 Main.immediate 调度器运行，避免异步文件读取恢复后违反导航主线程约束；主题通过解包 Context 获取窗口，设置系统栏图标明暗。 |
| 本地状态 | 即时更新 StateFlow，100 ms 合并突发更新，单写入协程执行 JSON 编码和原子落盘；失败保留最新快照并重试，界面提示保存异常。 |
| 持久化边界 | 切后台触发 flush；下载调度前及后台任务结束时等待持久化，确保 WorkManager 与任务记录一致。异常强制终止仍可能丢失尚未落盘的最后一小段修改。 |
| 界面重组 | 根界面只订阅主题和动效偏好；列表排序、过滤、映射与日期格式化避免重复执行，列表补充稳定 key/contentType。 |
| 网络 | API 与下载通过 OkHttp 异步回调处理响应；协程取消会取消底层请求；API JSON 解码在 Default 调度器完成；相同失效令牌的刷新串行复用。 |
| 下载 | 进度最多约每 250 ms 更新一次；每次执行使用独有临时文件；暂停、取消与替换任务不会并发写入同一个临时文件。 |
| 详情 | 账号隔离、5 分钟有效期、显式刷新绕过新鲜缓存；远端写入使旧缓存失效，失效水位跨进程保存；网络异常可回退有效的已有副本。 |
| 阅读器 | 段落投影、繁简转换和查找在后台完成；停止滚动 500 ms 后合并保存进度，离开/切后台补存；按可见视口翻页，修复过滤空段落后的查找定位。 |
| 刷新与动效 | 刷新保留内容和局部状态，失败保留原内容并提供重试；内容以 220 ms 淡入与 8 dp 位移进入，阅读工具栏以覆盖方式滑入，显示隐藏不再改变正文布局。 |
| 图片 | 应用共用 Coil 加载器，限制缓存，阅读插图预留空间，支持加载与失败反馈。 |
| 文件工具 | 读取文本、处理 EPUB/OCR 在后台执行，使用输入快照计算后一次性更新结果，处理时阻止重复操作。 |
| 发布体积 | 在已有 R8 优化基础上启用资源压缩。 |

## 缓存预算

| 缓存 | 上限与清理策略 |
| --- | --- |
| 章节内存 | 最多 24 章、估算 12 MiB，按最近使用淘汰。 |
| 本地文档内存 | 最多 4 本、估算 32 MiB，按最近使用淘汰；原始文件保持独立保存。 |
| 章节磁盘 | 256 MiB，首次访问建立索引，之后增量维护，写入时淘汰最久未使用章节。 |
| 详情磁盘 | 32 MiB，按获取时间淘汰；时间戳记录请求开始时间，防止在途旧响应被误判为新内容。 |
| 图片内存 | Coil 可用内存预算的 15%。 |
| 图片磁盘 | 128 MiB，由 Coil 管理。 |

设置中的「阅读与图片缓存」在后台统计和清理章节、详情、图片。清理不会删除本地导入文档、源文件、下载、书签或偏好。缓存写入失败不会阻止阅读已成功获取的网络章节。

「减少动态效果」覆盖新增内容过渡、书架重排、阅读工具栏、插图及阅读滚动动效；系统关闭动画时继续遵循 Android 的动画缩放机制。

## 交互动效补充

- 页面导航按方向短距离滑动并淡入，返回时反向退出；底部和宽屏侧栏的当前图标轻微放大，同一导航项重复点击不会重建页面。
- 书籍、菜单和文章条目沿用水波纹，并增加 0.985 倍按压反馈；选择项在固定图标位置显示勾选，避免选中后推动相邻选项。
- 书架整理栏与收藏夹操作栏展开收起，离场时立即停用其操作；书籍、文章、评论及下载列表的增删和重排有短过渡，书架勾选有底色反馈。
- 书籍详情、文章正文/讨论与编辑/预览切换时保留各自滚动位置。内容过渡只绘制当前页面，不复制有网络请求或草稿副作用的子组件。
- 下载进度在两次数据更新之间平滑推进；状态图标、完成操作区和卡片高度随状态变化。阅读搜索栏、独立亮度控件展开收起，关闭搜索时释放输入焦点。
- 封面加载后渐入，内存缓存命中时直接显示。页面内标签跳过首次进入，避免与导航和首载过渡叠加；不添加持续装饰动画或逐项滚入的错峰动画。

主要时长为 160–220 ms，透明度与缩放尽量在绘制阶段读取，不因每帧动画重新组合整页。「减少动态效果」立即完成新增过渡；重新启用动效不会重播当前内容。

## 验证方式

新增 JVM 回归测试覆盖状态合并、并发写入顺序、失败重试、LRU 容量、缓存有效期与失效水位、请求及响应体读取取消、译文投影及查找定位。

新增无网络 Compose 测试覆盖不同内容标识之间的结果隔离、刷新期间保留内容与子组件状态、失败刷新后的重试。MotionTest 覆盖快速切换时单个子组件与状态保留、过渡中减少动效立即生效、跳过首次动画及重新启用动效不重播。AppFlowTest 覆盖本地书架整理、阅读搜索、阅读偏好、下一章、模拟下载状态及深色设置。

```powershell
./build.ps1 -Tasks @('testDebugUnitTest', 'assembleDebug', 'lintDebug', 'assembleDebugAndroidTest') -Offline
./build.ps1 -Tasks @('testReleaseUnitTest', 'assembleRelease', 'lintRelease') -Offline
```

后续性能测量应使用真实低端设备上的 Release 构建，分别记录冷启动、长目录滚动、超长章节/插图和大体积 EPUB 场景。当前没有新增无依据的帧率或耗电改善百分比。

- 42 项 JVM 单元测试分别通过 Debug 和 Release；其中本轮新增 24 项。

- 模拟器 `Novelia_Test` 上最终构建的 7 项无账号设备测试通过：3 项刷新状态测试、3 项动效回归测试，以及包含书架整理、本地阅读、搜索、章节切换、下载状态、偏好与深色系统栏的完整流程。
