# 0.1.5 阅读主题调整（构建号 8）

## 本次修改

- 顶部工具栏、搜索区、底部工具栏和翻页按钮区域统一使用比正文稍深的背景，增强区域区分。
- 浅色阅读主题由近白色改为淡绿色，文字采用深绿灰色；黑白主题继续使用白底黑字。
- 阅读配色限定在正文和阅读工具栏内。阅读偏好、目录、朗读设置等面板沿用 App 的浅色／深色主题，避免选择黑白阅读主题后连设置面板也一起改色。
- 搜索输入文字、边框、光标和查找按钮使用当前阅读主题的文字颜色，保持浅色与深色阅读背景下的可读性。
- 保留工具栏透明度、覆盖式布局和减少动态效果设置。颜色变化不会改变正文空间，也不会因显示工具栏而重新分页。

## 阅读配色

| 阅读主题 | 正文背景 | 工具栏背景基色 |
| --- | --- | --- |
| 纸张 | `#F4ECD8` | `#DED2B8` |
| 浅色（淡绿） | `#E8F2E5` | `#CDDEC8` |
| 深色 | `#141A16` | `#050A07` |
| 黑白 | `#FFFFFF` | `#E0E0E0` |
| 跟随应用 | 沿用 App 正文背景 | 在 App 背景基础上加深 |

表中工具栏色号为不透明基色；实际显示继续按「工具栏透明度」叠加。阅读偏好中的「浅色」选项名称和已有设置值保持兼容。

## 验证

- Debug 编译、81 项单元测试和 13 项模拟器测试通过，覆盖工具栏显隐、透明度、分页与电子纸模式等现有行为。
- 在模拟器中逐一检查纸张、浅色、深色和黑白阅读主题，并验证黑白阅读下的偏好面板分别沿用 App 的浅色和深色配色。
- Debug Lint 无错误，保留项目已有的 20 项警告。
