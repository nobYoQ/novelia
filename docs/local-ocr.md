# 本地图片识字（已取消）

2026-09-20 按用户要求取消本地 OCR 功能。图片识别页面、模型下载、PaddleOCR SDK、ONNX Runtime / OpenCV 原生引擎及模型样本均已移除，正式安装包不再包含这些内容。

此前版本下载的模型会在升级后启动时后台清理。已存入书架的文本仍是普通本地书；未导出的校对草稿保留在原资料库中，可到「我的 → 文件工具 → 取回上次校对文本」继续整理或导出。没有旧草稿时不显示该入口。

普通文件工具中的「文本换行整理」继续保留，只处理已有文本，不进行图片识别。

当前交付与进度见 [优化更新说明](optimization-and-ocr.md) 和 [优化进度清单](optimization-progress.md)。
