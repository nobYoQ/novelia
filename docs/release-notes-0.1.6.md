9.17 : 更新版本为0.1.6

**电子纸阅读模式**

- 电子纸交互扩展到全应用，覆盖书架、发现、社区、设置表单和内置网页。
- 列表滑动过程中保持画面静止，松手后翻动一屏；支持「上一屏／下一屏」，横向筛选也可按屏切换。
- 阅读数值设置改用加减按钮，分卷排序提供上下按钮，插图支持分步移动；关闭电子纸模式后恢复普通交互，单书设置只影响当前阅读器。

**阅读器**

- 修复切换章节后工具栏自动打开的问题，保持原有显隐状态。
- 连续滚动与自动分页互相切换时保留段内阅读位置，修复切回分页后一直显示加载的问题。
- 修复切换语言或译文后分页与正文错配的问题；调整字号、行距和宽度时减少重复排版，过期计算可及时取消。
- 朗读内容准备移到后台，改善长章节的响应；没有可朗读正文时及时提示并结束。

**书架与文库**

- 文库小说支持挂载本地分卷，可折叠／展开、搜索分卷并直接阅读；支持更换所属文库和取消挂载，保留文件及阅读进度。
- 分卷支持拖动排序和上下移动，顺序按文库保存，重启后保留；搜索和批量整理期间暂停排序。
- 从文库下载并导入的新分卷，可自动挂载到已收藏的对应文库；旧文件和外部导入文件可手动挂载。
- 更新检查覆盖全部在线收藏，中断后继续检查后续作品；网络小说分级与文库分类分别保存，切换时不再相互影响。

**编辑与交互**

- 离开编辑页面时保存最后输入的草稿；评论发送期间继续输入的新内容不会被成功回调清空。
- 修复术语表保存期间的新修改被误标记为已保存的问题，补全文库编辑的冲突检查。
- Markdown 工具栏支持键盘 Tab 切换与 Enter 操作，文章和评论均保留所选文字并在格式化后返回编辑框。
- 特殊 Markdown 解析失败时回退显示原文；修复剧透展开后的白底显示，改善大字体下表单和下载按钮的可达性。

**下载与文件**

- 优化 EPUB 导入，按条目读取正文、插图直接落盘；导入前检查大小并通过索引查重，减少重复解析和内存占用。
- 修复删除、暂停、重新下载与任务完成之间的冲突，清理遗留临时文件，避免旧任务覆盖新状态。
- 导出期间页面重建后仍可继续保存，覆盖下载文件、本地书籍、文件工具和术语表。
- 优化长文本 OCR 整理，减少重复复制并支持取消。

**账号与同步**

- 请求和下载绑定发起时的账号，切换账号或退出后不再交付旧会话结果；退出后迟到的刷新不会恢复登录状态。
- 同一作品的在线操作与待同步操作统一排序，避免旧记录覆盖较新的阅读进度或收藏状态。
- 下载遇到登录凭据过期时支持同账号刷新重试，需要重新登录时给出明确提示。
