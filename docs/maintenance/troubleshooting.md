# 排障指南

[维护目录](README.md) · [文档首页](../README.md)

先记录提交/版本、构建类型、设备 API/ABI、操作入口和具体错误，再定位最小失败步骤。保留用户资料，不以卸载、清数据或删除全部缓存作为第一步。

## 构建与安装

| 现象 | 先检查 |
| --- | --- |
| 找不到 JDK / SDK | `./build.ps1 -CheckEnvironment`；手动路径、环境变量和 local.properties 优先级 |
| 缺少 Platform 或 NDK | SDK Manager 是否安装 Platform 36 和工具链指定 NDK |
| ECH 原生库构建失败 | Go 是否与 ech-native.properties 完全一致，NDK、gomobile 与模块缓存是否齐全 |
| IDE 成功，脚本离线失败 | 是否使用了不同 GRADLE_USER_HOME；离线不能补缺失依赖 |
| Unsupported targetAbi | 仅支持 universal、arm64-v8a、armeabi-v7a、x86_64、x86 |
| 缺少签名变量 | 是否误开正式 releaseSigning；普通测试无需发布私钥 |
| UPDATE_INCOMPATIBLE | 同包名不同证书，先备份并确认迁移方案 |
| VERSION_DOWNGRADE | 已安装版本码更高，使用正确升级版本 |
| 多设备或 runner 错误 | adb devices、ANDROID_SERIAL、测试 APK 和完整测试类名 |

环境与构建入口见[构建指南](../development/getting-started.md)，设备运行见[测试指南](../quality/testing.md)。`-CheckEnvironment` 不检查全部 Go/NDK/依赖，不启动 Gradle。

需要堆栈时对失败任务加 `--stacktrace`。签名任务不使用 build scan 或泄露环境的调试输出，不用禁用证书校验或清空全部缓存解决下载故障。

## 登录与请求

| 现象 | 定位方向 |
| --- | --- |
| 登录页打不开 | 当前线路、WebView、设备时间和认证服务连通性 |
| 网页成功但 App 未登录 | 消息回调、手动“完成登录”、刷新结果 |
| 401 | 对应来源会话和续期，不无限重试 |
| 403 | 服务端权限；本地按钮可见不保证允许 |
| 404 | 资源/接口不存在，保留原义 |
| 429 | 限流，检查重复触发和退避 |
| 账号或书源变化 | 旧绑定主动失效，在当前身份重新操作 |
| 退出后仍有书籍 | 本地设备资料正常保留，与会话无关 |

小说原站、镜像与论坛各自保存令牌。退出对应本地会话不会全局退出 SSO，也不会清除另一侧登录。规则见[认证](../network/authentication.md)。

连接异常用[网络诊断](../network/network-diagnostics.md)区分 DNS、TCP、TLS、HTTP 和正文阶段。帖子/评论超时先确认服务端是否已接收，不能默认安全重发。

## 同步没有发生

原站队列只发送当前账号待办；自动模式可能跳过被阻塞项，手动同步可重试。关闭自动开关保留待办。后台网络满足后仍受 WorkManager 调度，周期不是准确执行时刻。

WebDAV 另查是否启用、是否加入当前数据集、选中的类型、网络约束、认证/权限和冲突提示。ETag 或条件更新不可靠时会停止保护资料；已同步文件消失也不会自动重建。见[原站同步](../network/network-and-sync.md)和 [WebDAV](../network/webdav-sync.md)。

页面数据旧时检查账号/来源缓存键、写操作失效和 forceNetwork，而非直接清空书库。

## 文件和恢复

| 现象 | 定位方向 |
| --- | --- |
| 下载完成但无法导入 | 下载上限 512 MiB，导入上限 64 MiB；再核对格式和实际内容 |
| EPUB 缺章或乱序 | OPF/spine、资源引用和解析限制，不按 ZIP 文件名排序推断 |
| TXT 乱码 | BOM、UTF-8/GB18030 解码路径，保留原文件 |
| SRT 没有按时间播放 | 当前作为文本块阅读，不提供时间轴播放器 |
| 插图丢失 | 资源路径、marker、存储图片及正文引用 |
| 暂停后重新从头下载 | 当前无 Range 续传，属于既有行为 |
| 导出取消后残留 | PendingExportFiles 和分享文件生命周期 |
| ZIP 恢复失败 | 格式、版本、大小、哈希、引用；保留原备份，不跳过校验 |
| 恢复部分成功 | 可能书库已提交而标签失败，按界面重试，不把全库再覆盖一遍 |

容量与任务规则见[文件文档](../features/files-and-downloads.md)，恢复见[备份文档](../data/backup-and-recovery.md)。启动出现损坏保护时，保留受保护文件，使用恢复入口，不能写空状态掩盖错误。

## 阅读和界面

| 现象 | 先看 |
| --- | --- |
| 切译文、字号后跳位 | 原文索引、显示下标、字符锚点与布局代次 |
| 缺译文或回退日文 | 引擎顺序、段落缺失和缓存新鲜度 |
| 搜索不到整本 | 整本搜索只读本地或已缓存章节 |
| 改默认设置没生效 | 是否已有整份单书覆盖 |
| 暂停历史后仍能续读 | 历史和位置独立，当前预期行为 |
| 电子纸无惯性和动画 | 静态交互及单书/全局设置 |
| 面板打开位置变化 | 面板会话、自动收起、键盘和局部宽度 |
| 朗读失败 | TTS 引擎/语言包、音量/焦点、联网续章和服务状态 |
| 长章节慢 | 区分 I/O、投影、测量和渲染，按性能工具测量 |

实现入口见[阅读器](../features/reader.md)、[界面与导航](../architecture/ui-and-navigation.md)、[性能](../quality/performance.md)。

## 正式附件准备

先按[发布指南](releasing.md#准备附件)核对附件和签名前提。工作区不干净、标签不匹配、证书不符或目录已存在时，先核对输入和已有产物，不绕过检查。变更说明填写在 Release 正文，脚本不要求 CHANGELOG 文件。

对外反馈使用[缺陷表单](../../.github/ISSUE_TEMPLATE/bug_report.yml)，给最小复现和脱敏错误；不要附真实书库、凭据或完整日志。
