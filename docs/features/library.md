# 书架、收藏与阅读历史

[功能目录](README.md) · [文档首页](../README.md)

书架同时展示本地收藏、原站云端收藏和导入文档。开发时先确认改的是哪一种对象：书目、收藏关系、正文文件和阅读位置分别存储，不应互相代替。

书架页包含“我的书架”“本地文件”“云端收藏”三个标签。“我的书架”展示收藏书目及挂载分卷，“本地文件”平铺已加入书架的导入文档。

## 本地与云端的关系

| 对象 | 所在位置 | 说明 |
| --- | --- | --- |
| 本地书目、收藏夹、置顶、想读/在读/读完 | `LibraryState.books/folders` | 本设备共享 |
| 云端收藏及文件夹 | 原站账号 | 离线操作可在本机保留待办 |
| 本机精确位置 | `positions` | 章节、段落和偏移 |
| 本机历史 | `readingHistory` | 最近阅读记录，独立于位置 |
| 文库父项与本地分卷 | 本地书目关联 | 父项和每个子卷都有独立身份 |

“云端收藏同时保存到本地”默认开启，只在**显式加入或移动云端收藏**时为缺失书目建本地摘要。它不会下载正文，不改变已有本地文件夹、置顶和阅读状态。读取云端列表或补查进度不会触发它；取消云端收藏也保留本地资料。

## 整理与删除

本地支持类型、收藏夹、书名/作者、阅读状态和网络小说字数筛选。面板收起保留条件。字数补查和精确范围规则见[发现与搜索](discovery.md)。

删除收藏夹把书目移到默认收藏；批量改阅读状态不会改写精确位置。重命名本地书会更新文档目录、书架和笔记标题，保持文档 ID、源文件和去重哈希不变。

“我的书架”的批量整理提供“批量移出书架”，只处理所选书目，未选中的分卷在父项移出时解除挂载。默认保留正文和阅读记录，完成后可撤销；若开启“移出书架时删除本地副本”，确认框会说明所选本地副本同时删除且无法撤销。“本地文件”提供“批量删除”，确认后删除导入副本及对应下载并移出书架，保留导入前的原文件和阅读记录。两处均支持“彻底删除”，统一删除所选书籍、其本地分卷、对应下载及本机阅读资料。切换标签会清空批量选择。

移出但保留的本地副本仍参加导入去重，重新导入相同文件会把原书目加入书架并沿用阅读记录，不重新复制正文。查重只枚举已提交文档目录，复用源文件哈希索引。

| 操作 | 影响 |
| --- | --- |
| 从书架移除 | 移除收藏条目，整理分卷关系 |
| 删除本地小说 | 清理对应文档、章节、图片、原件、书目和关联下载，保留阅读记录 |
| 彻底删除 | 清理书籍及全部关联分卷、副本、下载和本机阅读资料；保留外部原文件与原站收藏 |
| 取消云端收藏 | 删除原站收藏关系 |
| 删除下载任务 | 清理下载副本，已导入文档仍保留 |
| 清缓存 | 清理可重建缓存，保留用户文档 |

撤销应在**当前状态上**补回条目，不能恢复整份旧书架快照，否则会覆盖撤销期间的新操作。

## 云端操作如何展示

列表按当前账号读取，再叠加本账号最新待同步意图。`PUT` 表示目标收藏夹，`DELETE` 表示已请求取消；“待同步”不表示服务端已经确认。

批量整理支持跨页选择。更换账号、小说类型、文件夹、排序或筛选会清空选择。批量加入本地保留已有条目属性；批量取消云端收藏逐本走队列，显示已完成、待同步和失败，会话变化则中止。队列排序与重试规则见[原站同步](../network/network-and-sync.md#哪些操作可以离线排队)。

## 文库与分卷

文库父项代表作品，本地分卷是导入的 `local` 文档。父项必须在本地收藏中，关联使用 `parentWenkuKey`；手动顺序保存在 `volumeOrder`。

有效挂载的子卷跟随父项分组，搜索命中子卷时保留父项作为上下文。完整兄弟集合内可调整顺序，未手动排列的部分按自然数字标题排序；电子纸使用按钮。

下载列表的“开始阅读”会确保父作品存在并挂载分卷。重复文件复用正文和阅读位置，重新挂到下载来源文库；普通导入不会因此改变已有分卷归属。

## 列表上的进度与更新

全书百分比按 `(chapterIndex + 1) / 已知章节总数` 计算，不混入章内段落位置。进入末章可显示 100%，不等于手工标记读完；有新章节后分母增大。旧位置缺少目录信息时显示“继续阅读”，不猜百分比。

原站记录通常只精确到章。补查详情得到有效章节后显示“读到第 N 章”；只有阅读时间时显示“有阅读记录”，未知值不能当未读或伪造 0%。比较云端秒级时间和本机毫秒时间前要换算，云端摘要不能覆盖本机段落锚点。

更新检查和完整详情刷新共用基线，比较章节数、译文计数和分卷。新增章节随阅读逐章确认；译文和分卷更新分别保留。手动标记更新已读保留检查基线及译文新鲜度。只检查本地收藏中的在线书籍，纯云端收藏不单独参加。

## 历史与续读

暂停历史只停止新增历史，续读位置仍保存；清空历史也保留位置。主站云端历史和本机历史分别清理。WebDAV 的历史与位置也有独立开关。

本机与原站都存在有效但不同的续读章节时，详情页让用户选择本次从哪里继续，见[书籍详情](book-details.md)。恢复正文仍使用阅读器的精确锚点，列表百分比只用于展示。
