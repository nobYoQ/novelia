# 书架、收藏与阅读历史

[功能目录](README.md) · [文档首页](../README.md)

书架同时展示本地收藏、原站云端收藏和导入文档。开发时先确认改的是哪一种对象：书目、收藏关系、正文文件和阅读位置分别存储，不应互相代替。

书架页包含“我的书架”“本地文件”“云端收藏”三个标签，支持点击标签或左右滑动切换。“我的书架”展示收藏书目及挂载分卷，“本地文件”平铺已加入书架的导入文档。各分区保留自己的滚动位置和筛选控件状态；切换分区会退出批量整理并清空勾选，批量删除执行期间暂时禁止切换。电子纸及减少动效模式下点击标签直接切页。

三个分区均在排序旁提供列表／网格切换。布局分别保存在本机设置和普通设置备份中，不参与 WebDAV 同步；旧书库默认保留列表。切换使用淡入淡出与轻微缩放，并以当前屏顶作品保持浏览位置；电子纸及减少动效模式直接切换。网格按宽度调整列数，封面保留书名、简短阅读进度、置顶和更新提示，长按拖选支持横向跨列、回划与边缘自动滚动。

“我的书架”的网格每部作品只占一个位置；已挂载的子卷不再平铺，封面下“本地 N 卷”打开分卷底部面板。面板区分本地挂载数量与出版卷数，提供最近分卷续读、逐卷阅读、完整卷名和进度、独立拖动排序、作品详情及挂载管理；长按卷册进入选择模式，沿用移动、状态、更多等操作。主网格全选只选择匹配条件的作品，面板全选只选择当前显示的分卷。搜索命中分卷时保留父作品并标注匹配数量，面板可切换为显示全部分卷而不改写书架筛选；仅显示匹配子集时不允许调整完整顺序。列表布局仍使用原有的内联分卷展开，“本地文件”网格则继续平铺文件，云端网格只呈现远端作品。

## 本地与云端的关系

| 对象 | 所在位置 | 说明 |
| --- | --- | --- |
| 本地书目、收藏夹、置顶、想读/在读/读完 | `LibraryState.books/folders` | 本设备共享 |
| 云端收藏及文件夹 | 原站账号 | 离线操作可在本机保留待办 |
| 本机精确位置 | `positions` | 章节、段落和偏移 |
| 本机历史 | `readingHistory` | 最近阅读记录，独立于位置 |
| 文库父项与本地分卷 | 本地书目关联 | 父项和每个子卷都有独立身份 |

“云端收藏同时保存到本地”默认开启，只在**显式加入或移动云端收藏**时为缺失书目建本地摘要。它不会下载正文，不改变已有本地文件夹、置顶和阅读状态。读取云端列表或补查进度不会触发它；取消云端收藏也保留本地资料。

## 整理与删除

“我的书架”和“本地文件”常驻两行控件：收藏夹、搜索和筛选入口，以及结果数量和排序。收藏夹与排序直接使用下拉菜单，收藏夹菜单保留新建、重命名和删除。小说类型、阅读状态和网络小说字数条件收进底部筛选面板；面板内修改草稿，点击“应用筛选”后统一生效，取消或返回不应用。重置只清理面板中的筛选，不改变收藏夹、排序或搜索词。已启用的条件显示为可移除标签，收起搜索时仍显示关键词标签。电子纸及减少动画模式沿用静态面板。字数补查和精确范围规则见[发现与搜索](discovery.md)。

本地书架不再单独显示“批量整理”入口。长按书籍或已展开分卷进入选择模式并选中起点；继续按住拖动连续选取，回划恢复移出区间的原有选择，从已选书籍开始拖动则连续取消选择。靠近列表边缘自动滚动；松手后的普通滑动仍只滚动。点按切换单项勾选，顶部提供全选和完成，返回键退出选择模式。长按拖动期间保持列表起点，避免进入选择模式后条目从手指下跳开。

选择模式下，手机底部导航由“上方图标、下方文字”的操作栏接管，并隐藏续读按钮。各操作等宽排列，保留完整无障碍名称；本地书架提供移动、阅读状态、下载和更多，云端提供加入本地、清空选择和取消云端收藏。选中一本与多本使用相同入口，单本还可从“更多”进入原有管理菜单。下载仅对可下载的网络小说启用；空选和正在执行删除时禁用不适用操作。分卷拖动排序仍使用独立拖动手柄。

筛选面板使用统一的小标题与圆角矩形选项网格，大字号时自动减少列数。字数常用档位直接选择，自定义上下限按需展开；底部重置和应用按钮固定保留，输入错误时禁用应用。

删除收藏夹把书目移到默认收藏；批量改阅读状态不会改写精确位置。重命名本地书会更新文档目录、书架和笔记标题，保持文档 ID、源文件和去重哈希不变。

“我的书架”选择模式的“更多”提供“移出书架”，只处理所选书目，未选中的分卷在父项移出时解除挂载。默认保留正文和阅读记录，完成后可撤销；若开启“移出书架时删除本地副本”，确认框会说明所选本地副本同时删除且无法撤销。“本地文件”提供“删除本地副本”，确认后删除导入副本及对应下载并移出书架，保留导入前的原文件和阅读记录。两处均支持“彻底删除”，统一删除所选书籍、其本地分卷、对应下载及本机阅读资料。切换标签会清空批量选择。

移出但保留的本地副本仍参加导入去重，重新导入相同文件会把原书目加入书架并沿用阅读记录，不重新复制正文。查重只枚举已提交文档目录，复用源文件哈希索引。

| 操作 | 影响 |
| --- | --- |
| 从书架移除 | 移除收藏条目，整理分卷关系 |
| 删除本地小说 | 清理对应文档、章节、图片、原件、书目和关联下载，保留阅读记录 |
| 彻底删除 | 清理书籍及全部关联分卷、副本、下载和本机阅读资料；保留外部原文件与原站收藏 |
| 取消云端收藏 | 删除原站收藏关系 |
| 删除下载任务 | 清理下载副本，已导入文档仍保留 |
| 清缓存 | 清理可重建缓存，保留用户文档 |

撤销应在**当前状态上**补回条目，不能恢复整份旧书架快照，否则会覆盖撤销期间的新操作。

## 云端操作如何展示

列表按当前账号读取，再叠加本账号最新待同步意图。`PUT` 表示目标收藏夹，`DELETE` 表示已请求取消；“待同步”不表示服务端已经确认。

云端收藏同样使用两行紧凑控件：收藏夹、搜索、筛选，以及当前小说类型、本页数量和排序。收藏夹与排序为下拉菜单；网络／文库类型、书源、连载状态、分级和翻译来源放入底部面板，草稿点击应用后统一生效。书源使用与发现页相同的多选标签，直接展开并提供“全选”入口；云端仍允许取消全部书源，此时无匹配结果。云端文库不显示网络小说专用筛选。

云端同样通过长按进入选择模式，支持单点、长按拖选和边缘自动滚动；普通滑动只滚动。顶部提供全选本页／取消本页全选和完成，底部使用图标加文字的操作栏。普通书目行不再提供取消收藏按钮，取消单本或多本均从选择模式发起并确认；已排队取消的书目仍保留行内撤销入口。翻页保留其他页的选择，更换账号、小说类型、文件夹、排序或筛选会清空选择。批量加入本地保留已有条目属性；取消云端收藏逐本走队列，显示已完成、待同步和失败，会话变化则中止。队列排序与重试规则见[原站同步](../network/network-and-sync.md#哪些操作可以离线排队)。

## 文库与分卷

文库父项代表作品，本地分卷是导入的 `local` 文档。父项必须在本地收藏中，关联使用 `parentWenkuKey`；手动顺序保存在 `volumeOrder`。

列表中的“卷”使用原站出版目录的卷数，与详情页一致；中文、日文上传文件分别用于下载和更新检查，不相加作为出版卷数。旧收藏或列表摘要尚无出版卷数时暂不显示，打开详情或检查更新后补齐。

有效挂载的子卷跟随父项分组，搜索命中子卷时保留父项作为上下文。完整兄弟集合内可调整顺序，未手动排列的部分按自然数字标题排序；电子纸使用按钮。

下载列表的“开始阅读”会确保父作品存在并挂载分卷。重复文件复用正文和阅读位置，重新挂到下载来源文库；普通导入不会因此改变已有分卷归属。

## 列表上的进度与更新

全书百分比按 `(chapterIndex + 1) / 已知章节总数` 计算，不混入章内段落位置。进入末章可显示 100%，不等于手工标记读完；有新章节后分母增大。旧位置缺少目录信息时显示“继续阅读”，不猜百分比。

原站记录通常只精确到章。补查详情得到有效章节后显示“读到第 N 章”；只有阅读时间时显示“有阅读记录”，未知值不能当未读或伪造 0%。比较云端秒级时间和本机毫秒时间前要换算，云端摘要不能覆盖本机段落锚点。

更新检查和完整详情刷新共用基线，比较章节数、译文计数和分卷。新增章节随阅读逐章确认；译文和分卷更新分别保留。手动标记更新已读保留检查基线及译文新鲜度。只检查本地收藏中的在线书籍，纯云端收藏不单独参加。

## 历史与续读

“我的书架”右下角提供紧凑的续读悬浮按钮，位于底部导航栏上方。列表顶部使用圆角矩形，分三行显示“继续”、小说名和章节，宽度最多 184 dp；向下浏览后收成 48 dp 的圆角方形播放按钮，点击仍直接恢复本机阅读位置，回到顶部重新显示文字。两种状态均使用适度圆角，背景与点击区域随内容容器完整缩放，文字和图标淡入淡出；减少动画或电子纸模式下直接切换。目标是书架中最近阅读过的书，筛选不改变续读目标。列表末尾留出按钮空间；批量整理、“本地文件”和“云端收藏”分区不显示。电子纸模式下按钮避开翻屏栏，没有阅读位置时不显示。

暂停历史只停止新增历史，续读位置仍保存；清空历史也保留位置。主站云端历史和本机历史分别清理。WebDAV 的历史与位置也有独立开关。

本机与原站都存在有效但不同的续读章节时，详情页让用户选择本次从哪里继续，见[书籍详情](book-details.md)。恢复正文仍使用阅读器的精确锚点，列表百分比只用于展示。
