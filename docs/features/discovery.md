# 发现、搜索与标签

[功能目录](README.md) · [文档首页](../README.md)

发现页向原站查询作品，再应用客户端筛选。服务器负责内容搜索；本地负责辅助表达式、屏蔽、字数补查和标签译名。排查结果不对时，先分清问题发生在哪一层。

## 搜索如何执行

```text
输入文字或链接
  → 用户提交
  → 可识别书源链接：打开书籍/章节
  → 普通查询：保存条件、回第一页、请求原站
  → 补齐必要元数据、应用本地筛选
  → 显示结果
```

输入草稿 `query` 与当前结果对应的 `submitted` 分开。提交搜索或恢复保存的搜索后重置页码，修改来源或筛选条件后重置对应分区的页码；加载身份包含这些条件和账号能力，旧响应不能覆盖新查询。

每次打开搜索编辑时，光标默认位于保留草稿的末尾，可直接追加文字；编辑过程中手动移动光标或选择文字后，输入仍遵循当前光标与选区。

“为你发现、网络小说、文库小说”可点击顶部标签或左右滑动切换，首尾不会循环。搜索、保存的搜索与推荐区的“更多”使用同一个分页位置，标签随页面同步。三个分区分别保留滚动和控件状态，网络小说与文库小说的页码、结果缓存彼此独立，普通分区切换不重置已浏览的页码。最近多页结果按条件有界复用，翻回已读页恢复列表或网格位置；过期后保留内容刷新，失败可重试。排行榜也支持下拉和点击刷新。切换分区后收起搜索编辑，输入草稿和已提交关键词保留。普通模式平滑切页，墨水屏或减少动画时点击标签、搜索跳转直接到目标分区。

“为你发现”是网络热门与文库列表的有限展示。排行榜从发现页进入。内容书源标识在 [Providers.kt](../../app/src/main/java/cc/novelia/app/data/catalog/Providers.kt)，与原站/镜像的访问线路不是一个概念。

共用分页控件的“‹ 第 x / x 页 ›”始终相对分页区域居中，右侧箭头用于展开或收起下方的页码跳转输入框；窄屏或大字号导致空间不足时，展开箭头移到下一行居中，避免挤压翻页按钮。输入框默认收起，展开和收起使用高度过渡、淡入淡出与箭头旋转；电子纸和减少动效模式直接切换。有效跳转后清空输入、收起键盘及输入框，越界页码仍显示校验提示。

“文库小说”默认使用封面网格，手机双列，宽屏根据可用宽度增加列数。书名显示在封面底部的渐变遮罩上；筛选旁的布局按钮可切换回原有列表。切换时淡化并轻微缩放过渡，保留当前页、搜索条件和最上方作品所在行，不重新请求列表；电子纸或减少动效时立即切换。选择保存在本机并随普通设置备份导入导出，WebDAV 不同步该显示偏好。

## 字数筛选为什么需要继续查找

原站查询表达式中的章节数不是字数。字数筛选使用详情的 `totalCharacters`，最小/最大值包含边界；未知字数默认不通过，可选择保留。

开启后，客户端按原站顺序扫描，每批最多三页，得到至少二十条匹配或到达末页时停止。完成一页就显示已获结果并保存游标，后页失败不丢前页结果。“继续查找”接着扫描；原站总数不能作为本地匹配总数。

补查最多五个并发，使用精简字数/作者数据，不为每项构建完整目录。候选页短期内复用；字数缓存会结合来源、账号、更新时间和章节状态失效。“重新查找”主动更新候选及字数。具体有效期见 [NovelFilterCache.kt](../../app/src/main/java/cc/novelia/app/data/catalog/NovelFilterCache.kt)。

界面显示“12.3 万字”等概数，筛选仍使用精确值。书架也有字数筛选，但按本地候选批次补齐，见[书架](library.md)。

## 辅助查询

[SearchExpression.kt](../../app/src/main/java/cc/novelia/app/data/catalog/SearchExpression.kt) 把表单转换成原站表达式：

| 条件 | 输出形式 |
| --- | --- |
| 全部关键词 | 空格连接，转义特殊符号 |
| 任一关键词 | 括号内用竖线连接 |
| 完整短语 | 双引号包裹，处理特殊字符 |
| 排除词 | `-词` |
| 包含/排除标签 | `标签$` / `-标签$` |
| 章节数量 | `>数值` / `<数值` |

例如 `魔法 学院 异世界$` 表达两个关键词和一个标签。搜索始终提交标签原文，不发送本地中文译名。

辅助条件追加到手写查询时，保留原表达式，只处理已知标签重复和反向冲突。原站预处理对空格、尾随美元符号和反斜杠有约定，不能用简单拆词重排用户输入。

## 标签库和保存搜索

[KeywordStore](../../app/src/main/java/cc/novelia/app/data/catalog/KeywordStore.kt) 从用户访问过的数据收集标签，不下载全站词典。译名、分类、排序和用户编辑记录在本地保存，显示翻译也可使用内置映射。

- “全部”是虚拟筛选，“其他”是默认分类。删除普通分类会把标签移到“其他”，不会删除标签。
- 自定义译名和明确清空的译名优先于默认映射；升级不能撤销用户整理。
- 辅助搜索的候选、已选条件和“浏览全部标签”都按“未选择 → 包含 → 排除 → 未选择”循环。包含显示主题强调色，排除显示红色和删除线，颜色平滑过渡；电子纸或减少动效时即时切换。已选条件的 × 可直接移除。
- 辅助搜索中编辑标签需经“浏览全部标签 → 前往标签库”，返回后保留待应用的条件及浏览位置。
- “包含整类/排除整类”展开点击时全部可搜索成员，形成普通标签条件；之后改分类不会联动改变这次查询。
- 包含多个标签要求全部满足，任一排除标签命中即排除。不可搜索成员会跳过并说明数量。
- 标签上限默认不限；达到自定义上限后停止收集新标签，降低上限不删除已有词条。

最近搜索与保存搜索分开。保存搜索是可命名的完整条件组合，包括查询、类别、来源、状态、译文、排序、分级和字数范围；恢复后回第一页，并按当前账号权限限制有效分级。

词典可独立导入导出，完整搜索方案随资料备份保存。格式范围见[设置与笔记](settings-and-notes.md)。

## 本地屏蔽与封面

书籍、标签、作者屏蔽影响客户端可见性，不改变原站数据或分页总量。作者按完整名称忽略大小写匹配，多作者任一命中即隐藏。作者信息缺失时有限并发补查；离线补查失败可能仍保留条目，因此不能保证未知作者已被过滤。

远端有结果但本页都被本地筛掉时，界面可能为空，应保留调整条件的入口。发现和排行榜不显示书架阅读进度。

发现页的列表布局在书名下方分别显示“本地收藏”和“云端收藏”，文库网格则显示在封面下方，不遮挡插画。两者都有时同时显示，窄屏自动换行；都没有则不显示。云端只采用当前登录账号的收藏关系，尚未提交成功时显示“云端收藏待同步”；待同步的取消操作隐藏云端标记，具体进度由同步提示说明。退出登录后仍保留本地收藏标记。“云端收藏同时保存到本地”开启时，一次云端收藏也会产生本地收藏，因此可能同时显示两个标记。

推荐与搜索的列表布局共用同一种条目，作者、字数、卷数和更新时间只使用当前列表摘要，不从本地书架额外补入，也不显示书架的新增章节提醒。文库网格只展示封面、书名和已有的收藏标记。收藏与否只改变收藏标记；启用字数筛选或作者屏蔽后，按当前条件统一补查到的信息仍可展示，原站缺失的字段不凭空补齐。

网络小说默认封面按连载状态和内容分级配色；`R18` 或 `性描写` 参与该分级，不能从标题或任意标签猜测。旧摘要未知时使用中性色，详情可补齐。规则见 [CoverPresentation.kt](../../app/src/main/java/cc/novelia/app/ui/components/book/CoverPresentation.kt)。

## 代码与验证

页面位于 [ui/discover](../../app/src/main/java/cc/novelia/app/ui/discover)，表达式、链接、过滤与词典位于 [data/catalog](../../app/src/main/java/cc/novelia/app/data/catalog)。

回归优先选择 `SearchExpressionBoundaryTest`、`NovelLocalFilterTest`、`NovelFilterCacheTest`、`KeywordCatalogTest`、`BookVisibilityTest`、`SavedSearchPresetTest`。`DiscoverSwipeTest` 覆盖分区滑动边界、标签与程序跳转同步、分区状态恢复、搜索草稿保留和横向搜索记录的手势。其他设备测试覆盖条件切换、页码重置、空结果、标签分类批选、大字号和电子纸交互，命令见[测试指南](../quality/testing.md)。

`DiscoverWenkuLayoutTest` 验证文库网格点击、两种布局之间的浏览位置、重建恢复、切换动画与快速反向切换、电子纸翻屏和空结果分页。`DiscoverLayoutSettingsTest` 验证旧设置默认值、布局选择序列化及 WebDAV 隔离。
