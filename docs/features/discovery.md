# 发现、搜索与标签

[功能目录](README.md) · [文档首页](../README.md)

发现页向原站查询作品，再应用客户端筛选。服务器负责内容搜索；本地负责辅助表达式、屏蔽、字数补查和标签译名。排查结果不对时，先分清问题发生在哪一层。

## 搜索如何执行

```text
输入文字或链接
  → 用户提交
  → 可识别书源链接：打开书籍/章节
  → 普通查询：保存条件、回第一页、请求原站
  → 补齐必要元数据、应用本地筛选
  → 显示结果
```

输入草稿 `query` 与当前结果对应的 `submitted` 分开。修改分类、来源或条件后重置页码，加载身份包含这些条件和账号能力；旧响应不能覆盖新查询。

“为你发现”是网络热门与文库列表的有限展示。排行榜从发现页进入。内容书源标识在 [Providers.kt](../../app/src/main/java/cc/novelia/app/data/catalog/Providers.kt)，与原站/镜像的访问线路不是一个概念。

## 字数筛选为什么需要继续查找

原站查询表达式中的章节数不是字数。字数筛选使用详情的 `totalCharacters`，最小/最大值包含边界；未知字数默认不通过，可选择保留。

开启后，客户端按原站顺序扫描，每批最多三页，得到至少二十条匹配或到达末页时停止。完成一页就显示已获结果并保存游标，后页失败不丢前页结果。“继续查找”接着扫描；原站总数不能作为本地匹配总数。

补查最多五个并发，使用精简字数/作者数据，不为每项构建完整目录。候选页短期内复用；字数缓存会结合来源、账号、更新时间和章节状态失效。“重新查找”主动更新候选及字数。具体有效期见 [NovelFilterCache.kt](../../app/src/main/java/cc/novelia/app/data/catalog/NovelFilterCache.kt)。

界面显示“12.3 万字”等概数，筛选仍使用精确值。书架也有字数筛选，但按本地候选批次补齐，见[书架](library.md)。

## 辅助查询

[SearchExpression.kt](../../app/src/main/java/cc/novelia/app/data/catalog/SearchExpression.kt) 把表单转换成原站表达式：

| 条件 | 输出形式 |
| --- | --- |
| 全部关键词 | 空格连接，转义特殊符号 |
| 任一关键词 | 括号内用竖线连接 |
| 完整短语 | 双引号包裹，处理特殊字符 |
| 排除词 | `-词` |
| 包含/排除标签 | `标签$` / `-标签$` |
| 章节数量 | `>数值` / `<数值` |

例如 `魔法 学院 异世界$` 表达两个关键词和一个标签。搜索始终提交标签原文，不发送本地中文译名。

辅助条件追加到手写查询时，保留原表达式，只处理已知标签重复和反向冲突。原站预处理对空格、尾随美元符号和反斜杠有约定，不能用简单拆词重排用户输入。

## 标签库和保存搜索

[KeywordStore](../../app/src/main/java/cc/novelia/app/data/catalog/KeywordStore.kt) 从用户访问过的数据收集标签，不下载全站词典。译名、分类、排序和用户编辑记录在本地保存，显示翻译也可使用内置映射。

- “全部”是虚拟筛选，“其他”是默认分类。删除普通分类会把标签移到“其他”，不会删除标签。
- 自定义译名和明确清空的译名优先于默认映射；升级不能撤销用户整理。
- “包含整类/排除整类”展开点击时全部可搜索成员，形成普通标签条件；之后改分类不会联动改变这次查询。
- 包含多个标签要求全部满足，任一排除标签命中即排除。不可搜索成员会跳过并说明数量。
- 标签上限默认不限；达到自定义上限后停止收集新标签，降低上限不删除已有词条。

最近搜索与保存搜索分开。保存搜索是可命名的完整条件组合，包括查询、类别、来源、状态、译文、排序、分级和字数范围；恢复后回第一页，并按当前账号权限限制有效分级。

词典可独立导入导出，完整搜索方案随资料备份保存。格式范围见[设置与笔记](settings-and-notes.md)。

## 本地屏蔽与封面

书籍、标签、作者屏蔽影响客户端可见性，不改变原站数据或分页总量。作者按完整名称忽略大小写匹配，多作者任一命中即隐藏。作者信息缺失时有限并发补查；离线补查失败可能仍保留条目，因此不能保证未知作者已被过滤。

远端有结果但本页都被本地筛掉时，界面可能为空，应保留调整条件的入口。发现和排行榜不显示书架阅读进度。

网络小说默认封面按连载状态和内容分级配色；`R18` 或 `性描写` 参与该分级，不能从标题或任意标签猜测。旧摘要未知时使用中性色，详情可补齐。规则见 [CoverPresentation.kt](../../app/src/main/java/cc/novelia/app/ui/components/book/CoverPresentation.kt)。
