# 社区、评论与草稿

[功能目录](README.md) · [文档首页](../README.md)

社区根入口连接独立论坛；小说评论使用论坛的外部资源接口，旧站文章保留主站接口。帖子使用论坛会话，小说评论使用小说会话。页面在 [ui/community](../../app/src/main/java/cc/novelia/app/ui/community)，协议和权限规则见[论坛接口](../network/forum-api-preview.md)。

## 列表与文章收藏

论坛分类从服务端读取，列表支持最近活跃、最新发布、浏览最多和评论最多。搜索范围随入口不同：

| 入口 | 搜索范围 |
| --- | --- |
| 全部帖子 | 将 q 发给服务器，在所选分类查询 |
| 我的帖子 / 云端收藏 | 筛选当前页标题 |

全部帖子可按当前分类的一个标签筛选，与搜索和排序同时生效；选择“全部标签”或再次点击已选标签可清除条件，切换分类会清除标签并回到第一页。列表、云端收藏、我的帖子、详情和编辑预览均显示标签徽标，颜色跟随服务端索引，深色与电子纸模式保持文字可辨认。

标签栏默认收起，可通过列表工具栏的标签筛选按钮展开。收起不清除筛选条件，按钮上的标记提示仍有标签生效。

文章详情的「收藏文章／取消收藏」直接操作论坛账号的云端收藏，状态来自当前账号的帖子详情。请求期间禁用按钮，服务端确认成功后才改变状态；失败保留原状态并提示错误。未登录时进入论坛登录，登录成功返回原文章继续收藏；取消登录丢弃续接意图。

论坛本地收藏及其正文副本已移除。旧版本书库或备份里的 `savedArticles` 不再读取或恢复，旧长文本载荷中的草稿仍兼容读取，下一次保存只写草稿。云端收藏通过「我的 → 云端收藏」查看；旧站文章保留阅读和编辑入口，没有云端收藏接口。

## 从草稿到发布

新帖草稿入口不要求登录，可以保留多篇草稿；论坛编辑器仍需加载分类与标签。编辑、预览、保存草稿与远端发布分别处理，权限不足也不应丢掉输入。

```text
载入原帖/新建 → 恢复草稿 → 编辑与预览
  → 校验会话、分类、权限和长度
  → 捕获发送快照 → 直接请求服务端
  → 成功：只清理与发送快照相同的草稿
  → 失败：保留输入与错误信息
```

论坛用 Unicode 码点计长度，标题 2–100、正文 1–20,000、评论 1–1,000，最多三个标签。分类权限按 slug，提交用当前分类 ID；只有数字 ID 的旧草稿需重新选分类。

标签由当前分类提供，选择区自动换行，满三个后仍可取消已选标签。切换分类会清空选择，没有标签的分类显示说明；编辑原帖与恢复草稿会过滤已经失效的标签。预览显示当前已选标签，发布和修改通过 `tagIds` 保存，取消所有选择会提交空数组。

帖子和评论不加入原站离线队列。请求超时可能发生在服务端已接收之后，重试前需要核对结果，不能自动重复新建。旧站草稿继续使用主站编辑器，不自动迁移到论坛。

## 草稿生命周期

| 类型 | 键 |
| --- | --- |
| 论坛新帖 | `article:forum-new:<UUID>`，兼容旧固定键 |
| 主站新帖 | `article:new:<UUID>`，兼容 `article:new` |
| 已有文章 | `article:<id>` |
| 主站评论 | `comment:<site>:<parent>` |
| 论坛评论 | `forum-comment:<postId>:<userId或guest>:<目标>` |
| 小说评论 | `novel-comment:<site>:<userId、username或guest>:<目标>` |

草稿保存在设备共享的 `LibraryState.drafts`。论坛评论键包含账号，其他草稿不能因此被推断为账号隔离；退出不会自动清除它们。

文章约 700 ms 防抖保存，[EditorDraft.kt](../../app/src/main/java/cc/novelia/app/ui/markdown/EditorDraft.kt) 负责离开时读取最新输入和提交后的条件清理。“保存草稿并退出”等待持久化，失败保留编辑器。慢请求期间继续输入后，成功回调必须保留新文字。

## 评论与回复

讨论页默认收起评论框，点击右下角圆角评论按钮展开；回复、编辑操作会直接展开对应输入。关闭按钮或返回键可收起，草稿保留；发送成功且输入未改变时自动收起。锁定讨论不显示新评论入口。展开、收起及按钮动效遵守“减少动态效果”和电子纸模式。

论坛一级评论与回复独立分页。一级响应可带回复计数和首屏正文，客户端校验后种入列表级缓存，默认仍折叠。展开时优先复用首屏；后续页或不兼容响应走回复接口。

缓存跟随帖子、列表刷新和论坛身份，每串保留最近三页；滚出屏幕或收起重开不丢已读页，离开列表才清理。明确的零回复直接展示；缺计数的旧响应才有限并发补查，失败保持未知。

回复任何子评论都提交根评论 ID。修改评论只发正文。普通作者修改/删除评论和删除帖子有时间限制，管理员条件另行处理，最终由服务端授权。

网络小说和文库小说由 `NovelCommentsPanel` 调用论坛的外部小说评论接口，使用小说账号会话，与帖子评论共用分页和回复缓存。小说讨论标识分别为 `web-{provider}-{id}`、`wenku-{id}`，详见[小说评论接口](../network/forum-api-preview.md#小说评论)。隐藏和屏蔽同时作用于一级评论与回复。

旧站文章仍由 `CommentsPanel.kt` 处理：读取参数是 `parentId`，发布正文的字段是 `parent`。屏蔽和锁定需同时作用于一级评论、摘要和回复面板。

## Markdown 编辑与链接

正文、预览和评论共享解析规则，论坛评分使用半星精度。解析器在 AST 层处理扩展，避免破坏代码块、已有链接和图片；渲染实现见[界面与导航](../architecture/ui-and-navigation.md#markdown-和编辑器)。

选中单行文字后原生粘贴 HTTP(S) 地址，可生成 Markdown 链接；无选区、多行、非网址或转换后超限时保留普通粘贴。操作仍支持光标、撤销/重做和草稿保存，不改系统剪贴板。

站内链接由统一分派进入书籍、帖子、原生守则或网页；旧原站域名有明确映射，不按路径相似度改写外站 URL。

## 守则和账号记录

守则页先展示缓存或内置副本，再检查线上部署对应内容。更新失败或结构不识别时保留可用内容。提示可关闭，守则入口保留在论坛菜单。

处罚未读状态只在社区相关前台生命周期检查。展示记录后按响应快照 ID 确认已读，失败可重试；旧账号响应不能写入新账号。抓取守则和处罚的协议细节见[论坛接口](../network/forum-api-preview.md#处罚未读与社区守则)。

## 验证重点

优先检查草稿恢复、预览切换、发送期间继续输入、旧分类重选、回复缓存、账号切换、屏蔽和刷新失败。JVM 测试看 `ArticleDraftsTest`、`EditorStateRegressionTest`、`MarkdownLinkPasteTest` 及论坛合约测试；设备测试在 [ui/community](../../app/src/androidTest/java/cc/novelia/app/ui/community) 和 [ui/markdown](../../app/src/androidTest/java/cc/novelia/app/ui/markdown)。

普通回归使用合成内容和模拟响应。真实发帖、修改、删除会改变远端内容，不属于默认只读联调。
