# 社区、评论与草稿

[功能目录](README.md) · [文档首页](../README.md)

社区根入口连接独立论坛；小说评论使用论坛的外部资源接口。旧站文章、评论接口与原生编辑器已移除，旧帖子链接使用网页打开。帖子使用论坛会话，小说评论使用小说会话。页面在 [ui/community](../../app/src/main/java/cc/novelia/app/ui/community)，协议和权限规则见[论坛接口](../network/forum-api-preview.md)。

## 列表与文章收藏

论坛分类从服务端读取，排序菜单提供最近活跃、最新更新、浏览最多和评论最多；`newest` 保留接口兼容，但不显示“最新发布”，恢复旧筛选状态时使用最近活跃。列表优先显示帖子更新时间，修改过的帖子标注“更新”。搜索范围随入口不同：

| 入口 | 搜索范围 |
| --- | --- |
| 全部帖子 | 将 q 发给服务器，在所选分类查询 |
| 我的帖子 / 云端收藏 | 筛选当前页标题 |

全部帖子可按当前分类的一个标签筛选，与搜索和排序同时生效；选择“全部标签”或再次点击已选标签可清除条件。分类分别保留标签、页码和浏览位置，搜索或排序变化时重置页码。列表、云端收藏、我的帖子、详情和编辑预览均显示标签徽标，颜色跟随服务端索引，深色与电子纸模式保持文字可辨认。

标签栏默认收起，可通过列表工具栏的标签筛选按钮展开。收起不清除筛选条件，按钮上的标记提示仍有标签生效。

论坛分类支持点击标签和在帖子列表上左右滑动切换，两种方式都会恢复目标分类的全部帖子浏览状态。文章详情的正文与讨论也支持左右滑动，保留正文滚动位置和评论草稿；点击标签时遵守减少动态效果与电子纸设置。

已有缓存时，分类元数据在后台静默刷新，帖子列表只显示一个刷新圆圈，避免同时出现加载条。首次加载和刷新失败仍有提示；减少动态效果与电子纸模式使用文字提示。

文章详情的「收藏文章／取消收藏」直接操作论坛账号的云端收藏，状态来自当前账号的帖子详情。请求期间禁用按钮，服务端确认成功后才改变状态；失败保留原状态并提示错误。未登录时进入论坛登录，登录成功返回原文章继续收藏；取消登录丢弃续接意图。

论坛本地收藏及其正文副本已移除。旧版本书库或备份里的 `savedArticles` 不再读取或恢复，旧长文本载荷中的草稿仍兼容读取，下一次保存只写草稿。云端收藏通过「我的 → 云端收藏」查看。

## 从草稿到发布

新帖草稿入口不要求登录，可以保留多篇草稿；论坛编辑器仍需加载分类与标签。编辑、预览、保存草稿与远端发布分别处理，权限不足也不应丢掉输入。

帖子草稿箱同时列出新帖和已发布帖子的修改草稿，支持续写与删除。进入已发布帖子的编辑页时先加载最新原帖；存在不同的本地草稿时，需选择“使用最新帖子”（删除该修改草稿）或“继续本地草稿”，不再静默用旧草稿覆盖原帖。取消选择并返回会保留草稿。

```text
载入原帖/新建 → 新帖恢复草稿，已有帖子选择是否恢复 → 编辑与预览
  → 校验会话、分类、权限和长度
  → 捕获发送快照 → 直接请求服务端
  → 成功：只清理与发送快照相同的草稿
  → 失败：保留输入与错误信息
```

论坛用 Unicode 码点计长度，标题 2–100、正文 1–20,000、评论 1–1,000，最多三个标签。分类权限按 slug，提交用当前分类 ID；只有数字 ID 的旧草稿需重新选分类。

标签由当前分类提供，选择区自动换行，满三个后仍可取消已选标签。切换分类会清空选择，没有标签的分类显示说明；编辑原帖与恢复草稿会过滤已经失效的标签。预览显示当前已选标签，发布和修改通过 `tagIds` 保存，取消所有选择会提交空数组。

帖子和评论不加入原站离线队列。请求超时可能发生在服务端已接收之后，重试前需要核对结果，不能自动重复新建。旧站的新帖及修改草稿保留标题和正文，在当前编辑器中按新帖续写，需重新选择分类后手动发布。

## 草稿生命周期

| 类型 | 键 |
| --- | --- |
| 论坛新帖 | `article:forum-new:<UUID>`，兼容旧固定键 |
| 恢复的旧站草稿 | 保留 `article:new:<UUID>`、`article:new`、`article:<旧ID>`，按新帖续写 |
| 论坛帖子修改 | `article:f-<ID>` |
| 论坛评论 | `forum-comment:<postId>:<userId或guest>:<目标>` |
| 小说评论 | `novel-comment:<site>:<userId、username或guest>:<目标>` |

草稿保存在设备共享的 `LibraryState.drafts`。论坛评论键包含账号，其他草稿不能因此被推断为账号隔离；退出不会自动清除它们。

文章约 700 ms 防抖保存，[EditorDraft.kt](../../app/src/main/java/cc/novelia/app/ui/markdown/EditorDraft.kt) 负责离开时读取最新输入和提交后的条件清理。“保存草稿并退出”等待持久化，失败保留编辑器。慢请求期间继续输入后，成功回调必须保留新文字。

已有帖子的草稿只保存与本次载入原帖不同的编辑内容：仅打开、预览或退出不会生成草稿，改回原帖内容也会清理草稿。

## 评论与回复

讨论页默认收起评论框，点击右下角圆角评论按钮展开；回复、编辑操作会直接展开对应输入。关闭按钮或返回键可收起，草稿保留；发送成功且输入未改变时自动收起。锁定讨论不显示新评论入口。展开、收起及按钮动效遵守“减少动态效果”和电子纸模式。

论坛一级评论与回复独立分页。一级响应可带回复计数和首屏正文，客户端校验后种入列表级缓存，默认仍折叠。展开时优先复用首屏；后续页或不兼容响应走回复接口。

缓存跟随帖子、列表刷新和论坛身份，每串保留最近三页；滚出屏幕、收起重开以及短时间离开后返回都可复用已读页。跨列表快照还有总条数、内存预算和两分钟有效期限制，清缓存、账号变化与写入失效不能复用旧身份结果。明确的零回复直接展示；缺计数的旧响应才有限并发补查，失败保持未知。

回复任何子评论都提交根评论 ID。论坛和小说的新评论均要求注册满 30 天；编辑器提前提示可评论日期，保留草稿，到期自动更新发送按钮。修改已有评论只发正文，不应用新评论的注册时长限制。普通作者修改/删除评论和删除帖子有发布后 20 分钟限制，管理员不受此修改时限影响，最终由服务端授权。

网络小说和文库小说由 `NovelCommentsPanel` 调用论坛的外部小说评论接口，使用小说账号会话，与帖子评论共用分页和回复缓存。小说讨论标识分别为 `web-{provider}-{id}`、`wenku-{id}`，详见[小说评论接口](../network/forum-api-preview.md#小说评论)。隐藏和屏蔽同时作用于一级评论与回复。

## 账号黑名单

黑名单管理入口仅在论坛「我的 → 账号黑名单」，可读取、按用户 ID 添加或取消拉黑。评论区顶部不单独占用一行入口；帖子详情与评论中的操作按钮显示“拉黑”或“取消拉黑”。写入确认成功后刷新帖子、收藏、一级评论和回复缓存；操作失败保留现状并显示原因。

黑名单保存在服务端，最多 1000 人，列表只返回用户 ID 和加入时间。管理页和帖子操作使用论坛会话，小说评论内的拉黑操作使用小说会话，账号与线路切换后旧响应不能更新新页面。新响应的 `authorBlocked` 会保留在模型中，旧响应缺失时默认为未拉黑。

原有按用户名保存的本地屏蔽继续生效，可在设置中管理；游客评论菜单提供“本地屏蔽”。本地名单不自动上传，也不因取消账号拉黑而删除。

## Markdown 编辑与链接

正文、预览和评论共享解析规则，论坛评分使用半星精度。解析器在 AST 层处理扩展，避免破坏代码块、已有链接和图片；渲染实现见[界面与导航](../architecture/ui-and-navigation.md#markdown-和编辑器)。

选中单行文字后原生粘贴 HTTP(S) 地址，可生成 Markdown 链接；选区本身已是 HTTP(S) 网址时直接替换。无选区、多行、非网址或转换后超限时保留普通粘贴。操作仍支持光标、撤销/重做和草稿保存，不改系统剪贴板。

站内链接由统一分派进入书籍、帖子、原生守则或网页；旧原站域名有明确映射，不按路径相似度改写外站 URL。

## 守则和账号记录

守则页先展示缓存或内置副本，再检查线上部署对应内容。当前内置副本核对于 2026-10-15 的部署 `6bae949`，解析器接受已知的新旧权限表行标识，并继续拒绝未知动态表达式；升级后不复用旧版权限缓存。更新失败或结构不识别时保留可用内容。提示可关闭，守则入口保留在论坛菜单。

处罚未读状态只在社区相关前台生命周期检查。展示记录后按响应快照 ID 确认已读，失败可重试；旧账号响应不能写入新账号。抓取守则和处罚的协议细节见[论坛接口](../network/forum-api-preview.md#处罚未读与社区守则)。

## 验证重点

已加载的社区列表在文章返回、发现与社区切换时直接恢复。普通屏幕在列表顶部继续下拉、松手即可刷新当前页；空列表也可下拉，刷新期间保留原内容并防止重复请求，失败显示重试入口。列表末尾的“刷新帖子”同时供点击和电子纸模式使用。

优先检查草稿恢复、预览切换、发送期间继续输入、旧分类重选、回复缓存、账号切换、屏蔽和刷新失败。JVM 测试看 `ArticleDraftsTest`、`EditorStateRegressionTest`、`MarkdownLinkPasteTest` 及论坛合约测试；设备测试在 [ui/community](../../app/src/androidTest/java/cc/novelia/app/ui/community) 和 [ui/markdown](../../app/src/androidTest/java/cc/novelia/app/ui/markdown)。

普通回归使用合成内容和模拟响应。真实发帖、修改、删除会改变远端内容，不属于默认只读联调。
