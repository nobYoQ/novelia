# 设置、书签与笔记

[功能目录](README.md) · [文档首页](../README.md)

设置并不全保存在同一个地方，也不都会迁移。修改前先确认它属于阅读资料、单书覆盖，还是这台设备的连接和系统配置。

## 设置分类

“我的”页将阅读历史、下载管理放在主卡片，书架更新、书签与笔记、文件工具放在快捷入口；设置、屏蔽、同步和备份归入“偏好与数据”，“帮助与关于”保留独立卡片。宽屏并列显示阅读入口与偏好分组，窄屏或大字号下纵向排列，沿用应用的浅色、深色与电子纸交互。

账号区使用与背景接近的独立卡片，保留登录、身份、注册时间和退出菜单。登录后点击“账号权限”，以浮层小卡片查看社区发布、书籍编辑的可用状态，不挤动下方入口；点击外部、关闭按钮或系统返回键即可收起。小绿仍支持点击切换表情和跳跃，在离屏、减少动效或电子纸模式下按原有规则暂停动画。

设置首页按用途提供六个入口，进入后只显示该类选项；返回回到分类首页，重建页面会恢复当前分类。

| 分类 | 内容 |
| --- | --- |
| 阅读与朗读 | 默认排版、阅读配色、电子纸、状态栏与朗读通知 |
| 外观与操作 | 应用主题、桌面图标、减少动效与剪贴板提示 |
| 书架与下载 | 云端收藏本地副本、更新提醒、Wi-Fi 下载、导入与移出清理 |
| 网络与同步 | 启动检查应用更新、WebDAV、书源线路、ECH 诊断与日志 |
| 内容与标签 | 小说评论、屏蔽、标签分类、容量和词表迁移 |
| 数据与备份 | 缓存、普通设置导入导出、阅读资料备份 |

镜像登录页的“切换书源线路”直接进入“网络与同步”。缓存大小只在打开“数据与备份”时统计。

## 设置保存在哪里

| 设置 | 保存位置与作用 |
| --- | --- |
| 应用主题、减少动效、屏蔽等 | `LibraryState` |
| 默认阅读偏好 | `LibraryState.reader` |
| 单书阅读偏好 | `bookSettings[bookKey]`，整份快照 |
| 标签词典和分类 | 独立 `KeywordStore` |
| 小说书源线路 | 本机 `book_sources` 配置 |
| 桌面图标 | 本机 `launcher_icons` 和系统组件状态 |
| WebDAV 连接和密码 | 独立本机配置，密码加密保存 |
| 登录会话 | 对应 `Session`，不进入资料备份 |

默认设置改变后，有单书快照的作品仍使用自己的配置。关闭“仅应用于这本书”会删除快照，再继承默认值。阅读偏好控件显示当前值与默认值的差异，细节见[阅读器](reader.md)。

设置通过 `LocalStore.update` 发布，再合并写盘。新增字段需同时检查默认值、控件范围、单书覆盖、电子纸切换和各类导出校验。

## 几个容易混淆的开关

- **电子纸与减少动效**影响不同：前者还有按屏滚动和按钮操作，后者主要关闭动画与连续反馈。自动分页独立选择。
- **下载仅 Wi-Fi**实际使用 WorkManager 的非计费网络约束；阅读预读的同名选项检查 Wi-Fi transport。它们不约束所有 HTTP 请求。
- **原站自动同步、更新通知、WebDAV**各有开关和调度，关闭一种不代表关闭所有联网。
- **启动时检查应用更新**默认开启，每次进入前台后延迟约 3 秒检查 GitHub 正式版，不阻塞首屏；退到后台会取消本次检查。可在“网络与同步”关闭，“关于”中的手动检查仍然可用。选择“稍后”会暂停提醒一天，“不再显示此版本”只忽略该版本，均不阻止之后启动时检查。
- 更新弹窗的**下载更新**和“帮助与关于”的两个下载按钮会先检查最新发行信息；当前已是最新版本时不下载。下载过程中在应用内显示进度条、百分比和已下载大小，也可选择**后台下载**。下载任务及安装包身份会保存，重新进入应用后恢复进度或完成状态。
- 下载完成并校验后提示**立即安装 / 稍后**。立即安装打开系统安装器；首次需要“允许安装未知应用”时先进入授权页，返回后继续安装。稍后会保留 APK，再次点击下载按钮先检查更新：远端还是同一个包就直接安装已下载版本，有更新则下载新包。APK 保存在应用外部下载目录，无需额外存储权限；失败、文件丢失或校验不一致可重新检查下载。**发行说明**保留 Release 页面入口。
- **下载预览包**检查滚动 `preview` Pre-release 的构建编号、版本码及附件身份，不参与正式版自动更新提醒。发现新构建后先提示预览版本不稳定，明确确认后才开始下载。预览包使用测试签名，可能无法覆盖正式签名安装的版本；切换前应备份阅读资料。预览发布须使用默认 `preview` 标签及构建信息附件才能由此入口找到；旧预览包没有内嵌构建编号时，使用 APK 摘要辅助判断是否已经安装。
- **云端收藏同时保存到本地**只保存缺失书目摘要，不下载正文，也不移除已有收藏。
- **清缓存**保留导入文档、书架、笔记和下载成品。
- **隐藏小说评论**不隐藏整个社区；屏蔽用户也只是客户端过滤。

通知还受 Android 运行时权限和系统调度限制，开启提醒不保证立即通知。

桌面图标在 App 整体退到后台后才切换，前台只保存待处理选择；Android 12 及以上启动画面跟随已生效入口。添加资源和升级规则见[图标说明](../../app/launcher-icons/README.md)。

## 设置与标签的导出

| 格式 | 包含 | 不包含 |
| --- | --- | --- |
| 普通设置 JSON | 默认阅读、主题、减少动效、屏蔽、下载约束、筛选收起、收藏副本、剪贴板提示、标签容量等白名单偏好 | 单书设置、书架、位置、笔记、草稿、标签内容、会话和任务 |
| 标签库 JSON | 标签原文、译名、分类、空分类与使用记录 | 账号、书籍、标签容量偏好 |
| 阅读资料 ZIP | 阅读资料、本地文档、单书设置等 | 登录凭据、缓存和待执行任务 |

普通设置以 [SettingsBackup.kt](../../app/src/main/java/cc/novelia/app/data/model/SettingsBackup.kt) 为完整字段依据，新增 `LibraryState` 字段不会自动加入该格式。整库迁移见[备份与恢复](../data/backup-and-recovery.md)。

启动检查应用更新的开关保存在 `LibraryState`，旧数据缺少该字段时默认开启；普通设置 JSON 会保留该开关，WebDAV 不同步此本机联网偏好。

标签导出为 `novelia-keywords` 版本 1；导入先校验和预览，再合并。支持原生格式、旧数组及第三方 `src/dst/info` 数组，本机已编辑译名和分类优先。第三方重复原文保留首条并提示；原生格式和旧数组仍拒绝重复。词表文件上限 32 MiB，非法或超限合并不部分写入。

标签数量默认不限，可改为正整数。降低上限不删除现有数据；超过容量的新增/合并整体拒绝，已有词条仍可编辑。容量设置随普通设置和资料备份迁移，独立词表不改变它。

## 书签与笔记

二者保存在 `LibraryState.notes`。一条记录有书籍键、章节、原始段落索引、摘录、可选笔记正文和标题快照。清空笔记文字可以保留书签位置。

[NotesScreen.kt](../../app/src/main/java/cc/novelia/app/ui/notes/NotesScreen.kt) 支持按书籍筛选、搜索书名/章节/摘录/正文、编辑、文本分享和删除撤销。旧记录标题由 [NotePresentation.kt](../../app/src/main/java/cc/novelia/app/ui/notes/NotePresentation.kt) 补全。撤销在最新状态上重新加入记录，不覆盖其他操作。

笔记位置使用原始段落索引，跳回阅读器时要经过正确的坐标转换。移出书架后笔记可能仍在，但能否返回正文取决于章节或本地文件是否还可用。

笔记不上传到原站阅读历史；WebDAV 可同步网络书籍的书签和笔记，本地文档资料通过 ZIP 迁移。

## 修改后的检查

默认与单书分别验证，切换电子纸后确认偏好保留；导出检查白名单，非法值导入应失败。笔记检查空标题、原书移除、搜索、删除撤销和定位。

相关入口：`ReaderPreferencesTest`、`KeywordLibraryTest`、`BookVisibilityTest`、`CloudFavoriteLocalCopyTest`，以及 [settings 设备测试](../../app/src/androidTest/java/cc/novelia/app/ui/settings)。系统分享、通知、图标和文件选择器需要设备验收。
