# 设置、书签与笔记

[功能目录](README.md) · [文档首页](../README.md)

设置并不全保存在同一个地方，也不都会迁移。修改前先确认它属于阅读资料、单书覆盖，还是这台设备的连接和系统配置。

## 设置分类

“我的”页将阅读历史、下载管理放在主卡片，书架更新、书签与笔记、文件工具放在快捷入口；设置、屏蔽、网络与同步和备份归入“偏好与数据”，“帮助与关于”保留独立卡片。宽屏从账号区开始分为两栏：左侧依次为紧凑账号卡、阅读入口和快捷入口，右侧为偏好分组和关于卡；两栏按实际内容共用总高度，自动分配卡片间距，使顶部和底边对齐。窄屏或大字号下纵向排列，沿用应用的浅色、深色与电子纸交互。

这些二级页面共用与主页接近的底色、圆角卡片和间距；宽屏限制内容宽度，大字号可滚动到各项操作。阅读历史的来源、暂停开关与记录共用滚动区域，避免控件挤占记录列表。备份仍先检查文件，再确认合并；下载批量操作、笔记编辑与删除撤销保持原有行为。

账号区使用与背景接近的独立卡片，保留登录、身份、注册时间和退出菜单。登录后点击“账号权限”，以浮层小卡片查看发表评论、书籍编辑的可用状态；发表评论按当前角色和注册满 30 天判断。卡片不挤动下方入口，点击外部、关闭按钮或系统返回键即可收起。小绿仍支持点击切换表情和跳跃，在离屏、减少动效或电子纸模式下按原有规则暂停动画。

设置首页按用途提供六个入口，进入后只显示该类选项；返回回到分类首页，重建页面会恢复当前分类。六个分类（含网络与同步）与外层页面共用整页水平位移和淡入淡出转场，返回时反向播放，标题栏随内容一起过渡。电子纸、减少动效或系统关闭动画时直接切换；转场中开启减少动效会立即结束动画，保留当前页状态。

| 分类 | 内容 |
| --- | --- |
| 阅读与朗读 | 默认排版、阅读配色、电子纸、状态栏与朗读通知 |
| 外观与操作 | 应用主题、A 屏黑、桌面图标、边缘工具栏、减少动效与剪贴板提示 |
| 书架与下载 | 云端收藏本地副本、更新提醒、Wi-Fi 下载、导入与移出清理 |
| 网络与同步 | 原站账号同步状态、自动同步、待处理记录与重试、WebDAV、书源线路、ECH 诊断与日志、启动检查应用更新 |
| 内容与标签 | 小说评论、屏蔽、标签分类、容量和词表迁移 |
| 数据与备份 | 缓存、普通设置导入导出、阅读资料备份、卸载保留数据说明 |

“我的”的“网络与同步”、设置中的同名分类和镜像登录页的“切换书源线路”共用一个页面。原站同步仅显示当前账号的记录，WebDAV 独立显示连接状态并进入原有配置页；两者不会相互启停。旧 `sync` 和 `settings?section=NETWORK` 路由仍可使用。缓存大小只在打开“数据与备份”时统计。

“书籍章节缓存”按占用空间列出已缓存的网络小说，显示每本书的章节数和大小，点击后确认单独清理。旧版缓存会根据已知书目和目录恢复归属，无法识别的部分单列为“未识别的旧版章节缓存”，也可以清理；打开对应小说详情可补充识别。原有“阅读与图片缓存”仍用于清空全部网络正文、详情和图片。

“数据与备份”说明了卸载时的系统保留选项：Android 10 及以上默认启用此能力，用户在卸载确认框中决定是否保留，是否显示及默认勾选状态由系统决定，应用内没有动态开关。Android 8/9 显示先导出备份的提示。重新安装需保持包名和签名一致，卸载前仍建议备份，详见[卸载时保留应用数据](../data/backup-and-recovery.md#卸载时保留应用数据)。

## 设置保存在哪里

| 设置 | 保存位置与作用 |
| --- | --- |
| 应用主题、减少动效、屏蔽等 | `LibraryState` |
| 边缘工具栏位置和快捷入口 | `LibraryState.edgeToolbar`，本机显示偏好 |
| 默认阅读偏好 | `LibraryState.reader` |
| 单书阅读偏好 | `bookSettings[bookKey]`，整份快照 |
| 标签词典和分类 | 独立 `KeywordStore` |
| 小说书源线路 | 本机 `book_sources` 配置 |
| 桌面图标 | 本机 `launcher_icons` 和系统组件状态 |
| WebDAV 连接和密码 | 独立本机配置，密码加密保存 |
| 登录会话 | 对应 `Session`，不进入资料备份 |

默认设置改变后，有单书快照的作品仍使用自己的配置。关闭“仅应用于这本书”会删除快照，再继承默认值。阅读偏好控件显示当前值与默认值的差异，细节见[阅读器](reader.md)。

设置通过 `LocalStore.update` 发布，再合并写盘。新增字段需同时检查默认值、控件范围、单书覆盖、电子纸切换和各类导出校验。

## 边缘工具栏

默认启用，位于右侧窗口安全区域 55% 的高度。32 dp 圆点带四格快捷入口图标，触控区域为 48 dp；点击展开阅读历史、下载管理。直接上下拖动，松手后保存相对位置。圆点位置以窗口安全区域为基准，切换页面、阅读菜单显隐和页面控件重新测量都不会挪动它；只有旋转或窗口缩放时按新窗口尺寸适配。

3 秒未操作会缩回边缘，只露出半圆，不透明度降至 45%；触控区域保留在屏幕内，再次点击直接展开。展开、拖动、按住或键盘焦点停留时不计闲置。页面切换和临时隐藏继承半隐藏状态及原有倒计时，隐藏期间计时继续；再次出现不会自动唤醒。面板向屏幕内侧打开，随圆点高度居中，靠近顶部或底部时自动避让边界；入口较多或字号较大时内容可滚动。点击外部、关闭按钮、圆点或系统返回键可收起。

“设置 → 外观与操作 → 边缘工具栏”可关闭工具栏、选择左右侧、调整或重置高度、选择 3/5/8 秒闲置或关闭半隐藏、调整半隐藏不透明度（30%–80%）、配置阅读时显示方式及下载任务数量。快捷入口可添加、移除和排序，保留 1–5 个，可选阅读历史、下载管理、书架更新、书签与笔记、文件工具、设置；点击“完成”保存，返回取消编辑。

阅读时默认跟随阅读菜单，也可始终隐藏或始终显示。圆点避开系统安全边界，系统状态栏隐藏时仍使用原有安全边距；面板额外避让根导航栏和阅读工具栏。键盘、弹窗、其他面板、登录或编辑页出现时暂时隐藏。普通模式下圆点原位淡入淡出，面板从圆点一侧轻微缩放并淡入淡出；快速切换时从当前进度继续，不移动圆点的锚点。

电子纸（含单书设置）、减少动效或系统关闭动画时，显隐和半隐藏立即切换；电子纸下圆点保持不透明。电子纸拖动期间只累计目标高度，松手后一次移动并保存，取消手势不改变位置；普通及仅减少动效模式保留手动跟手拖动。圆点作为拖动把手始终保持圆形。

位置和入口随普通设置 JSON 保存，不进入 WebDAV；阅读资料 ZIP 沿用全局偏好合并规则，空书库恢复时继承，已有书库保留本机配置。旧数据没有该字段时使用默认值；导入拒绝非法位置、重复或未知入口。

## 几个容易混淆的开关

- **电子纸与减少动效**影响不同：前者还有按屏滚动和按钮操作，后者主要关闭动画与连续反馈。自动分页独立选择。
- **纯黑显示模式（A 屏黑）**位于“外观与操作”的应用主题下方，默认关闭。开启后深色主题的页面底色使用纯黑，卡片使用近黑底色与细边框，菜单和弹层保留更亮的灰阶层次；跟随系统时仅在系统深色模式下生效。阅读配色选择“跟随应用”时正文和工具栏也使用纯黑，手动阅读配色与电子纸白底保持原样。切换即时生效，作为本机显示偏好保存，普通设置 JSON 保留，WebDAV 不同步。加载页通过轻量显示缓存沿用已保存的主题；Android 12 及以上同时为当前桌面图标保存对应的系统启动主题，跟随系统的启动背景可随系统深浅模式变化。
- **fuck 圆角**位于“外观与操作”，默认关闭。开启后应用卡片、按钮、输入框、导航指示器、弹层及阅读控件使用直角，关闭立即恢复；不改变间距、配色或功能。该彩蛋是本机偏好，普通设置 JSON 保留，WebDAV 不同步。插画、图标内容与 Android 系统界面不做改绘。
- **下载仅 Wi-Fi**实际使用 WorkManager 的非计费网络约束；阅读预读的同名选项检查 Wi-Fi transport。它们不约束所有 HTTP 请求。
- **原站自动同步、更新通知、WebDAV**各有开关和调度，关闭一种不代表关闭所有联网。
- **启动时检查应用更新**默认开启，每次进入前台后延迟约 3 秒检查 GitHub 正式版，不阻塞首屏；退到后台会取消本次检查。可在“网络与同步”关闭，“关于”中的手动检查仍然可用。选择“稍后”会暂停提醒一天，“不再显示此版本”只忽略该版本，均不阻止之后启动时检查。
- 更新弹窗的**下载更新**和“帮助与关于”的两个下载按钮会先检查最新发行信息；当前已是最新版本时不下载。下载过程中在应用内显示进度条、百分比和已下载大小，也可选择**后台下载**。下载任务及安装包身份会保存，重新进入应用后恢复进度或完成状态。
- 下载完成并校验后提示**立即安装 / 稍后**。立即安装打开系统安装器；首次需要“允许安装未知应用”时先进入授权页，返回后继续安装。稍后会保留 APK，再次点击下载按钮先检查更新：远端还是同一个包就直接安装已下载版本，有更新则下载新包。APK 保存在应用外部下载目录，无需额外存储权限；失败、文件丢失或校验不一致可重新检查下载。**发行说明**保留 Release 页面入口。
- **下载预览包**检查滚动 `preview` Pre-release 的构建编号、版本码及附件身份，不参与正式版自动更新提醒。发现新构建后先提示预览版本不稳定，明确确认后才开始下载。预览包使用测试签名，可能无法覆盖正式签名安装的版本；切换前应备份阅读资料。预览发布须使用默认 `preview` 标签及构建信息附件才能由此入口找到；旧预览包没有内嵌构建编号时，使用 APK 摘要辅助判断是否已经安装。
- **云端收藏同时保存到本地**只保存缺失书目摘要，不下载正文，也不移除已有收藏。
- **清缓存**保留导入文档、书架、笔记和下载成品。
- **隐藏小说评论**不隐藏整个社区；屏蔽用户也只是客户端过滤。

通知还受 Android 运行时权限和系统调度限制，开启提醒不保证立即通知。

桌面图标在 App 整体退到后台后才切换，前台只保存待处理选择；Android 12 及以上启动画面跟随已生效入口。添加资源和升级规则见[图标说明](../../app/launcher-icons/README.md)。

## 设置与标签的导出

| 格式 | 包含 | 不包含 |
| --- | --- | --- |
| 普通设置 JSON | 默认阅读、主题、减少动效、边缘工具栏、屏蔽、下载约束、筛选收起、收藏副本、剪贴板提示、标签容量等白名单偏好 | 单书设置、书架、阅读位置、笔记、草稿、标签内容、会话和任务 |
| 标签库 JSON | 标签原文、译名、分类、空分类与使用记录 | 账号、书籍、标签容量偏好 |
| 阅读资料 ZIP | 阅读资料、本地文档、单书设置等 | 登录凭据、缓存和待执行任务 |

普通设置以 [SettingsBackup.kt](../../app/src/main/java/cc/novelia/app/data/model/SettingsBackup.kt) 为完整字段依据，新增 `LibraryState` 字段不会自动加入该格式。整库迁移见[备份与恢复](../data/backup-and-recovery.md)。

启动检查应用更新的开关保存在 `LibraryState`，旧数据缺少该字段时默认开启；普通设置 JSON 会保留该开关，WebDAV 不同步此本机联网偏好。

标签导出为 `novelia-keywords` 版本 1；导入先校验和预览，再合并。支持原生格式、旧数组及第三方 `src/dst/info` 数组，本机已编辑译名和分类优先。第三方重复原文保留首条并提示；原生格式和旧数组仍拒绝重复。词表文件上限 32 MiB，非法或超限合并不部分写入。

标签数量默认不限，可改为正整数。降低上限不删除现有数据；超过容量的新增/合并整体拒绝，已有词条仍可编辑。容量设置随普通设置和资料备份迁移，独立词表不改变它。

## 书签与笔记

二者保存在 `LibraryState.notes`。一条记录有书籍键、章节、原始段落索引、摘录、可选笔记正文和标题快照。清空笔记文字可以保留书签位置。

精确选文产生的划线或批注额外保存可选 `Note.selection`，包含文本来源、同源版本序号和字符范围；同一段可以有多条选文记录。它们与整段书签分别保存，清空笔记文字仍保留划线。阅读器段落面板的“本书书签与批注”会带入本书筛选，从记录返回正文时优先恢复到选中文字。只有划线、没有笔记正文的记录也属于 WebDAV“笔记”同步范围；未开启笔记同步时，书签同步不删除本机划线。

[NotesScreen.kt](../../app/src/main/java/cc/novelia/app/ui/notes/NotesScreen.kt) 支持按书籍筛选、搜索书名/章节/摘录/正文、编辑、文本分享和删除撤销。旧记录标题由 [NotePresentation.kt](../../app/src/main/java/cc/novelia/app/ui/notes/NotePresentation.kt) 补全。撤销在最新状态上重新加入记录，不覆盖其他操作。

笔记位置使用原始段落索引，跳回阅读器时要经过正确的坐标转换。移出书架后笔记可能仍在，但能否返回正文取决于章节或本地文件是否还可用。

笔记不上传到原站阅读历史；WebDAV 可同步网络书籍的书签和笔记，本地文档资料通过 ZIP 迁移。

## 修改后的检查

默认与单书分别验证，切换电子纸后确认偏好保留；导出检查白名单，非法值导入应失败。笔记检查空标题、原书移除、搜索、删除撤销和定位。

相关入口：`ReaderPreferencesTest`、`KeywordLibraryTest`、`BookVisibilityTest`、`CloudFavoriteLocalCopyTest`，以及 [settings 设备测试](../../app/src/androidTest/java/cc/novelia/app/ui/settings)。系统分享、通知、图标和文件选择器需要设备验收。
