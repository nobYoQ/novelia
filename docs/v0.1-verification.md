## 账号与服务限制

没有提供真实账号，因此没有向原站提交帖子、评论、收藏变更、术语变更或文库上传。上述写入功能依据原站公开源码接入，并具有权限提示、失败反馈与防重复提交控制；仍需真实账号端到端验收。

统一认证使用受限 WebView 与原站认证页，原生端通过原站刷新接口取得访问会话。只允许来自已指定原站来源的登录完成消息。未读取或存储用户密码。

原站浏览器扩展相关功能、日亚抓取和管理员控制台未作为原生能力实现。原生客户端没有绕过其权限、验证码或注册时长限制。

## 数据与失败恢复

- 本地文件不需要上传即可阅读；原始副本与处理输出分开保存。
- EPUB 解压有输入大小、解压大小和条目数限制，拒绝越界路径；插图以内部文件保存。
- 阅读位置按书籍与章节标识保存，云端历史只支持章节粒度。双方进度不同，由用户选择。
- 收藏/历史待同步项绑定发起账号；不对发帖和评论做自动重试。
- 下载完成状态依赖成功 HTTP 响应与实际文件写入，取消和错误不会显示为完成；暂停后重新下载。
- 凭据不进入普通配置备份、日志、下载 URL 或分享内容。
