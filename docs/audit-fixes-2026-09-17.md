# 审查问题修复

本轮处理 [项目审查](project-audit-2026-09-17.md) 的 F01–F22，并补充下载面板滚动、Markdown 键盘操作和术语表过滤优化。保留原有本地资料格式；没有执行生产账号写入。

## 修复对应表

| 问题 | 实现 |
| --- | --- |
| F01 账号隔离 | 请求捕获账号和登录代次；401 重试、响应交付与下载流均校验同一会话。账号切换后旧请求不能使用新账号重试。 |
| F02 旧队列覆盖新操作 | 同账号同资源的在线写入和重放共享互斥；先记录最新幂等意图，成功后清除，取消时只保留最新意图。 |
| F03 分页正文错配 | 测量结果包含对应正文与排版参数；输入不一致时不绘制旧结果，重排期间暂停旧页导航和进度保存。等值重排也更新快照实例，分页就绪后才显示页码。 |
| F04 Markdown 崩溃 | 备用字符耗尽时降级解析；外部内容的解析/渲染失败均显示原始文本。另修复原生焦点高亮覆盖剧透白底的问题，将展开范围合并后只重绘一次。 |
| F05 评论新输入丢失 | 成功回调仅清除与已提交快照相同的输入，保留发送期间新增内容及草稿。 |
| F06 术语表错误保存基线 | 请求体与成功后的 original 使用同一快照，等待期间的修改保持未保存。 |
| F07 导入内存 | 先校验文件大小；URI 受限流式落盘，EPUB 使用 ZIP 随机访问逐章解析，图片直接写入文件。声明及实际读取长度均校验。 |
| F08 草稿退出 | 保留输入防抖，离页同步提交最新快照；提交成功后的草稿不会被离页回调复活。 |
| F09 退出与刷新竞态 | 退出立即使原登录代次失效，旧刷新不能回写 token、profile 和 Cookie。 |
| F10 更新覆盖不足 | 每轮覆盖全部在线书籍，逐本保存游标，中断后从下一本继续。 |
| F11 阅读模式锚点 | 两种模式转换使用段内字符偏移；布局变化可重启恢复，避免捕获旧布局永久等待。保存回调使用最新模式，分页重新就绪时保存恢复的位置。 |
| F12 筛选串用 | 网络分级与文库分类保存为独立状态。 |
| F13 导出恢复 | 下载/本地文件仅保存可恢复 ID，工具与术语表先持久化导出快照，再保存快照 ID；文件选择器返回后流式复制，完成或取消后清理，丢失来源时明确提示。 |
| F14 文库并发校验 | 比较所有将写回的字段，与请求使用同一可编辑字段集合。 |
| F15 临时下载文件 | 统一实际 part 命名清理；启动清理遗留文件，删除任务清理旧文件，保护仍在运行的 Worker。同任务提交、删除、暂停与重试共用锁，并用兼容旧数据的工作 ID 阻止旧任务覆盖新状态。 |
| F16 下载认证 | 下载复用同账号 401 刷新重试，流读取时检查会话变化。 |
| F17 重复外部链接 | 重建仅恢复未消费的链接；新 Intent 同步到 Activity，不重放已消费链接。 |
| F18 空朗读队列 | 准备/读取时过滤空内容，无正文时提示并结束服务。 |
| F19 导入查重 | 持久化文档哈希索引，解析新书前查重；旧资料只在首次索引时读取正文。 |
| F20 朗读主线程 | 队列准备、文件读取和拆分移到后台；独立请求文件与语音序号隔离并发及迟到回调。 |
| F21 无效整章重排 | 测量防抖并逐段/逐批行检查取消；普通滑块松手提交，滚动锚点查询缓存并采用二分。 |
| F22 OCR 复制 | StringBuilder 累加，逐行检查取消，保留原段落与句子分隔行为。 |

下载面板改为可滚动布局，表单面板默认完整展开，保证大字体下底部操作可达；Markdown 工具栏保留键盘焦点，文章与评论在 Tab 转移焦点前保存选区，格式化后返回编辑器；术语列表按数据和防抖后的查询缓存过滤结果。README 的当前版本说明同步为 0.1.6。

## 兼容性与边界

- 应用已有的小说、插图文件、阅读进度与偏好格式保持兼容。新增哈希索引是可重建元数据，首次导入可能需要扫描旧文档一次。
- 下载上限仍为 512 MiB；应用内导入上限为 64 MiB，超过上限在读取前拒绝，下载原件仍可导出。EPUB 解压预算为 192 MiB，单个 XHTML/目录最多 8 MiB，文字最多 16 Mi 字符。TXT/SRT 也限制文字总量，仍需要在内存中解码正文。
- 已到达服务器的旧账号请求不能撤回；账号隔离阻止的是使用另一个账号重试或交付已失效结果。
- 文库使用客户端读取后比较；原站若没有条件写入接口，仍无法消除检查与写入之间的服务器端并发窗口。
- 未升级依赖或更改 SDK 目标。原有版本提示和弃用警告单独处理，避免与行为修复混杂。
