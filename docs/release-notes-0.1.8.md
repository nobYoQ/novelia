**阅读器**

- 整本搜索结果精确定位到命中文字，支持同一段落内多个结果、上一个／下一个结果和跨章跳转；连续滚动与自动分页均显示命中高亮。
- 切换章节时先加载目标正文，加载期间可取消；失败时保留当前章节与阅读位置，可重试或继续阅读。
- 统一连续滚动与自动分页的字重、主辅字号及间距，常用阅读设置前置，高级设置分组展示。
- 正文插图加载失败后可重试；朗读暂停后恢复最多重读当前句。

**大屏布局**

- 宽屏书籍详情并排展示简介与目录／讨论，切换标签或屏幕宽度时保留面板状态。
- 书架内容区达到 840dp 时启用「书架＋详情」双栏，支持选中高亮；阅读返回后仍停留在原书籍详情。
- 阅读区达到 840dp 时启用「目录＋正文」双栏，目录支持搜索、正倒序、当前章标记与定位。
- 切换宽窄布局时保留书架位置、所选书籍、目录筛选及正文位置；移出或删除所选本地书后清空对应详情。

**书架与操作**

- 下载列表按待登录、暂停、失败等状态显示对应操作；导入或下载完成后可直接进入阅读。
- 未登录时发起收藏，登录后可继续原操作，并可直接创建收藏夹。
- 完善本地文件删除确认；书架移除、笔记删除及待同步的云端移除支持撤销。
- 笔记显示书籍和章节信息，支持搜索及按书筛选；默认封面增加稳定配色和来源标签。
- 筛选显示条件摘要、重置入口，空结果提供放宽条件的操作。

**同步与账号**

- 书目行显示待同步、正在同步、失败或需要重新登录，并区分收藏、取消收藏和阅读进度操作。
- 支持在书目行重试当前书籍，成功后刷新云端列表，不会同时提交其他书籍的待同步操作。
- 切换账号或退出后重新登录时，旧会话任务和旧确认操作失效，避免操作串号。

**动效与电子纸**

- 筛选面板展开、收起时补偿列表位置，保留正在查看的书目及已填写条件。
- 减少页面与内容重复淡入，普通屏分页使用可打断的轻量过渡。
- 统一自定义过渡参数，面板、对话框、菜单、加载提示及内置网页适配「减少动态效果」和电子纸模式。
- 系统动画时长比例设为 0 时使用静态显示；内置网页同步关闭动画、过渡和平滑滚动。

**存储与性能**

- 本地小说目录与正文分开保存，按需读取单章；旧格式迁移失败时仍可继续读取。
- 文章和草稿正文独立保存，减少阅读进度变化时的重复保存，兼容已有阅读资料备份。
- 阅读、预读和批量缓存复用同章请求，离开后取消无效任务，减少重复请求与后台计算。
- 更新启动和常用导航的 Baseline Profile，保留已有轻量构建。
- 本版本不包含 OCR 识别或模型下载；升级清理旧模型，保留已导入书籍，旧校对草稿可从文件工具中取回。
