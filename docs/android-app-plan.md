# Novelia 安卓端功能规划

调研日期：2026-09-10。目标站点：[轻小说机翻机器人](https://n.novelia.cc/)。

本规划建议将 App 定位为「轻小说阅读、收藏追更与翻译协作客户端」，围绕书架、发现、翻译、社区、我的五个入口组织功能。普通用户的阅读和翻译贡献流程属于目标范围；管理员控制台作为可选扩展。

当前阶段只形成需求规划，尚未创建安卓工程或完成接口联调。

## 1. 调研依据与可信范围

本次直接浏览了首页、使用说明、网络搜索、网络小说详情、章节阅读器及设置、文库列表与详情、本地收藏、网络收藏、全局设置、黑名单、两个平台的排行页面、论坛、统一身份认证、GPT/GPT BETA/Sakura 工作区、交互翻译和小说工具箱，并阅读了站内使用教程、术语表指南与部分公开源码。

网站页面显示的构建时间为 `2026-09-04 03:52:32`，提交为 [db8d9b5f5758](https://github.com/auto-novel/auto-novel/commit/db8d9b5f5758b8b857131c9b5475ac564c116de3)。源码补充依据来自调研时可访问的 `main` 分支，不能据此认定每一项都与线上构建完全相同。

全文采用四种证据标记：

| 标记 | 含义 |
| --- | --- |
| 页面 | 已在浏览器看到页面或控件；仅看到按钮不代表已完成其业务操作 |
| 官方说明 | 依据站内维护者发布的教程 |
| 源码 | 公开仓库确认了入口或实现结构，尚待线上联调 |
| 增强 | 建议增加的安卓能力，不作为网站已有功能描述 |

当前浏览器为游客状态，因此没有实际验证账号登录成功、云端收藏读写、文库目录与下载、小说编辑、文件上传、翻译执行和回传，也没有发布帖子或评论。网络收藏接口实际返回了 401；文库目录明确要求登录。Kakuyomu 排行在本次默认条件下显示空列表，排行榜入口与筛选项已确认，实时榜单内容完整性仍待验证。

## 3. 安卓信息架构

| 一级入口 | 二级页面 | 主要用途 |
| --- | --- | --- |
| 书架 | 最近阅读、网络收藏、文库收藏、本地小说、收藏夹、阅读历史 | 继续阅读和管理收藏 |
| 发现 | 推荐、网络小说、文库小说、排行榜、搜索结果 | 找书和导入已支持的书源链接 |
| 翻译 | 任务、翻译器、交互翻译、术语表、文件工具 | 生成和管理翻译 |
| 社区 | 小说交流、使用指南、反馈与建议、文章与回复 | 交流、阅读教程、反馈问题 |
| 我的 | 账号与权限、下载管理、阅读偏好、屏蔽管理、缓存、帮助与关于 | 管理个人状态和设备设置 |

阅读器使用独立全屏页面。书籍详情聚合简介、目录、译文状态、收藏、下载和讨论入口；在手机上将这些内容分段或放入页签，避免要求用户滚过大量评论才能找到目录。

网站首页的热门网络小说、最新文库更新迁入“发现”的推荐页。搜索在“发现”顶部常驻，并支持从安卓系统分享菜单接收书源链接。底部导航保持五项，阅读与翻译操作保留清晰的返回路径。

## 4. 模块功能清单

优先级定义：P0 为第一版阅读闭环；P1 为覆盖普通用户主要功能所需的后续内容；P2 为增强体验及低频扩展。P1 仍是整体项目目标范围，不能因首版完成而视为全部完成。

### M01 账号与权限

**原站依据：页面、官方说明、源码。** 登录页嵌入 `auth.novelia.cc` 的统一身份认证，支持用户名/邮箱与密码登录、邮箱验证码注册和忘记密码入口。源码确认账号角色、注册日期及退出入口。[登录页](https://n.novelia.cc/auth)、[账号菜单源码](https://github.com/auto-novel/auto-novel/blob/main/web/src/pages/MainLayout.vue)

- P0：游客使用；复用现有账号的登录与退出；登录失效提示；登录后返回原页面。
- P0：展示账号状态与功能权限，区分未登录、权限不足、账号限制和普通网络错误。
- P1：接通现有注册、邮件验证、找回密码流程，优先复用统一认证页面。
- 接入待验证：认证回跳、会话更新、安卓端与兼容网页之间的会话衔接。
- 验收：从受限操作进入登录，完成后恢复原意图；取消登录可回到原页面；退出后不串用其他账号的缓存和收藏。

### M02 发现、搜索与书源链接

**原站依据：页面、官方说明。** 首页有热门网络小说与最新文库更新；搜索支持中日标题、作者和源站链接。网络筛选包含来源、连载状态、翻译类型和排序。[首页](https://n.novelia.cc/)、[网络小说](https://n.novelia.cc/novel)

- P0：首页推荐、网络与文库独立检索、最近搜索、分页/滚动加载、空结果与重试。
- P0：六类书源筛选、连载/完结/短篇筛选、GPT/Sakura 条件、更新时间/点击/相关性排序；文库保留实际支持的分类。
- P0：解析受支持的源站小说链接，识别网络小说系列和短篇，打开对应详情。
- P1：把 AND/OR、排除词、精确匹配、包含/排除标签、章节数范围做成可视化高级搜索；保留原始查询表达式入口。搜索语法依据[官方教程](https://n.novelia.cc/forum/64f3d63f794cbb1321145c07)。
- 增强：安卓分享接收、保存搜索条件、本地屏蔽小说和标签。官方教程将部分屏蔽和增强搜索介绍为站友脚本能力，不能假定原站有对应云同步接口。
- 验收：作者、日文标题和已收录源站链接能落到正确结果；筛选和返回后的列表位置可恢复；不支持的链接给出可理解的说明。

### M03 排行榜

**原站依据：页面。** 成为小说家吧提供流派、综合、异世界转移/转生入口；Kakuyomu 提供流派排行。不同平台的周期与状态条件不同。[小说家排行](https://n.novelia.cc/rank/web/syosetu/1)、[Kakuyomu 排行](https://n.novelia.cc/rank/web/kakuyomu/1)

- P0：平台、榜单类别、流派、周期、状态选择，点击榜单作品进入详情。
- P0：只展示该平台实际支持的条件，例如小说家页面有季度条件，Kakuyomu 本次页面没有季度条件。
- 增强：记住常用榜单条件，展示缓存时间。
- 验收：榜单条件与请求结果一致；空榜、抓取失败与加载中使用不同状态。当前不能承诺所有条件下的榜单数据都可用。

### M04 网络小说详情与目录

**原站依据：页面、官方说明、源码。** 样本详情已确认中日标题、作者、简介、标签、状态、字数、浏览量、译文数量、源站链接、关联文库、评论和目录。[样本详情](https://n.novelia.cc/novel/syosetu/n6093en)

- P0：书籍信息、开始/继续阅读、收藏、关联文库跳转、作者与标签搜索、源站打开。
- P0：卷/章节目录、正倒序、折叠、定位当前章节；区分原文和各译文的可用状态。
- P0：下载入口与设置；区分“已有内容可阅读”和“需要更新/生成翻译”。
- P1：更新元数据、抓取原文、选择翻译范围并排队；展示冷却时间及进度。
- P1：按权限编辑元数据、维护关联关系；具体可编辑字段在接口核对后确定。
- 增强：目录内搜索、未读章节标记、指定范围缓存。
- 验收：长目录定位流畅；章节标识不依赖屏幕序号；目录更新后不会因插入章节而跳到错误内容。教程描述的更新冷却应由服务端状态决定。

### M05 阅读器

**原站依据：页面。** 已实际打开网络章节与阅读设置。[阅读器](https://n.novelia.cc/novel/syosetu/n6093en/1)

- P0：日文、中文、中日、日中四种显示模式；有道/GPT/Sakura 译文切换、优先回退、并列比较、译文来源标识。
- P0：上一章、下一章、目录、详情、章节翻页与滚动阅读；退出恢复到原位置。
- P0：字号、字重、行距、内容宽度、缩进修正、亮暗/跟随系统及自定义阅读主题；简繁转换。
- P1：下划线样式、主辅文字透明度、每书独立偏好等细项。
- 增强：离线阅读、音量键翻页、单手点击区域、亮度与屏幕常亮、书签/笔记、段落搜索、系统文本分享。
- 增强：原生 TTS 朗读、语速、中文/日文语音、定时停止、通知栏控制。原站已看到“朗读语言”选项，本次未验证实际朗读流程；原生后台朗读属于独立实施项。
- 验收：切换语言和译文后保持段落锚点；缺失译文显示清晰的回退状态；离线时已缓存章节可读，未缓存章节不伪装成已缓存。

### M06 书架、收藏夹与阅读历史

**原站依据：页面、源码。** 收藏分网络、文库、本地三类；本地可创建收藏夹、搜索文件名并按添加时间/阅读时间/标题排序。阅读历史为登录后入口。[本地书架](https://n.novelia.cc/favorite/local)、[网络收藏](https://n.novelia.cc/favorite/web)、[路由](https://github.com/auto-novel/auto-novel/blob/main/web/src/router.ts)

- P0：三类书籍统一呈现、最近阅读卡片、收藏与取消收藏、收藏夹新建和整理、本地阅读位置记录。
- P0：在现有服务支持范围内接入网络/文库收藏和阅读历史；同步字段和粒度须通过接口确认。
- P1：批量移动/整理、筛选和排序、网络异常下的待同步操作、同步失败提示。
- 增强：未读更新标记、置顶、在读/想读/读完、离线收藏；没有服务端字段的状态只在 App 本地保存。
- 验收：收藏和阅读记录不串账号；重复同步不会重复添加；发生位置冲突时允许用户选择进度，不简单用“最大章节数”覆盖重读行为。

### M07 文库小说与分卷资源

**原站依据：页面、官方说明、源码。** 已确认作者、画师、出版社/文库、出版日期、封面组、标签、网络版关联与评论。源码确认登录后的上传、术语表、下载设置、卷列表和翻译参数组件。[文库详情](https://n.novelia.cc/wenku/6450c36184972153850fa673)、[文库源码](https://github.com/auto-novel/auto-novel/blob/main/web/src/pages/novel/WenkuNovel.vue)

- P0：文库检索、分类、详情、分卷浏览、译文进度和状态、符合条件的译本下载。
- P0：下载完成后加入本地书架阅读，或交给外部阅读器；使用统一的下载管理。
- P1：新建文库条目、重复检查、编辑元数据、维护分卷信息、上传文件、翻译排队与术语维护。
- P1：对接日亚元数据导入时明确其扩展依赖；不能直接假定安卓接口可用。
- 验收：登录和下载资格生效；不提供原站禁止的纯日文文库下载；文件版本与卷号不混淆；下载失败可以重试且不产生假完成记录。

### M08 本地文件阅读与翻译

**原站依据：页面、官方说明。** 本地导入入口明确支持 EPUB/TXT/SRT，工作区可打开本地书架。[本地收藏](https://n.novelia.cc/favorite/local)、[GPT 工作区](https://n.novelia.cc/workspace/gpt)

- P0：系统文件选择器导入 EPUB/TXT、本地书籍信息、目录、封面/插图显示、阅读和移除。
- P1：SRT 导入、时间轴保留与导出；本地文件加入翻译任务；维护本地术语表与译文。
- P1：中文、日文和站点翻译器支持的其他语种输入；保留原始文件并另存处理结果。
- 增强：重复文件检测、TXT 编码识别与手动纠正、目录规则预览、批量导入。
- 验收：文件导入前后编码和章节顺序正确；EPUB 插图不丢失；SRT 翻译后时间轴不改变。本地阅读不需要上传整个文件。

### M09 下载、导出与缓存

**原站依据：页面。** 网络小说下载设置支持 EPUB/TXT、中文/中日/日中、译文优先/并列、引擎次序及中文文件名；网络详情另有原文下载。[详情下载设置](https://n.novelia.cc/novel/syosetu/n6093en)

- P0：下载任务列表、取消/重试、保存目录、打开文件、安卓系统分享、可用空间与失败原因。
- P0：保留原站支持的语言组合、译文顺序和文件格式；网络小说和文库分别执行下载资格。
- P1：批量下载、Wi-Fi 条件、导出参数模板、缓存容量管理。
- 增强：章节缓存、增量更新、文件版本识别；续传只在服务器提供相应支持时启用。
- 验收：下载完成后文件真实可打开；取消任务不会被误记为成功；缓存清理与移除源文件在界面上区分清楚。

### M10 翻译中心

**原站依据：页面、官方说明。** 原站包含普通 GPT、GPT BETA、Sakura 与交互翻译四类界面。[GPT](https://n.novelia.cc/workspace/gpt)、[GPT BETA](https://n.novelia.cc/workspace/gpt-pipeline)、[Sakura](https://n.novelia.cc/workspace/sakura)、[交互翻译](https://n.novelia.cc/workspace/interactive)

| 子功能 | App 规划 | 优先级 |
| --- | --- | --- |
| 翻译器管理 | 名称、模型、服务地址、密钥、连接验证、启动/停止；敏感配置保存在设备安全存储中 | P1 |
| 普通 GPT | 对齐现有 GPT 队列、任务记录、失败重试和本地译本导出 | P1 |

| Sakura | 自建服务地址、共享服务、支持模型提示、共享负载入口；手机需使用实际可达地址 | P1 |
| 有道 | 已有译文阅读属于 P0；新译文生成及回传按扩展兼容结果接入 | P1，前置验证 |
| 任务中心 | 网络/文库/本地来源、排队、优先级、暂停/恢复、失败重试、完成记录、缓存管理 | P1 |
| 交互翻译 | 输入短文本、选择翻译器、应用术语表、结果复制与历史；对齐网页当前 5000 字符输入上限 | P1 |
| 后台与恢复 | 持久化章节/分块状态、网络恢复后续作、系统中断后提示恢复、通知栏进度和完成提醒 | P1，增强 |
| 费用信息 | 服务返回 usage 时记录消耗；支持用户填写价格进行估算，实际计费以服务商为准 | P2，增强 |

翻译中心可以在产品上统一呈现，但内部需要区分不同引擎和任务格式，不能假定普通 GPT 与 BETA 的缓存、分块或记录完全兼容。队列存在于本机时，应明确标注，避免让用户认为网页和手机会自动同步任务。

建议任务状态包括：排队、等待网络、执行中、用户暂停、系统中断、失败、已完成。状态必须细化到书籍、章节和分块，生成完成与服务器接收完成分开记录。

验收：任务中断后能从已确认的进度恢复；重试不会重复提交相同结果；失败原因能区分服务连接、限流、格式校验和回传拒绝；切换账号或术语版本不会污染已有结果。任何原生回传都需先验证站方支持的接口和校验要求。

### M11 术语表与翻译质量

**原站依据：页面、官方说明。** 交互翻译术语表提供逐项添加、批量导入/导出、JSON 下载与撤销删除；官方指南说明术语变更后，已有章节要选择过期内容重新翻译才生效。[术语表指南](https://n.novelia.cc/forum/660ab4da55001f583649a621)

- P1：小说公共术语表、本地文件术语表、交互翻译术语表分别管理。
- P1：编辑日文到中文映射、支持引擎允许的备注、批量导入/导出、重复与冲突提示。
- P1：术语变更预览，提示哪些译文需要重翻；接通现有过期译文处理机制。
- 增强：本地编辑草稿和变更比较、候选术语筛选、个人词表；公共与个人结果明确区分。
- 验收：修改公共术语不会被误认为已更新所有章节译文；术语文件导入后可以检查结果再提交；机器提取的候选术语保留人工校对步骤。

### M12 小说工具箱

**原站依据：页面。** 工具箱有术语候选提取、EPUB 图片压缩、TXT OCR 换行修复、EPUB 转 TXT。[工具箱](https://n.novelia.cc/workspace/toolbox)

- P1：片假名高频词提取、出现次数阈值、选择翻译器生成候选译名、导出术语表。
- P1：EPUB 图片格式、压缩率、缩放比例、效果预览和输出文件。
- P1：TXT OCR 多余换行修复；EPUB 转 TXT。
- 增强：批处理、原文件保留、前后差异预览、处理日志。
- 验收：输出可打开，文件处理可以取消，预览与结果一致；“OCR 换行修复”不描述为图片 OCR 识别。

### M13 论坛与评论

**原站依据：页面、源码。** 论坛有小说交流、使用指南、反馈与建议三个版块；列表有文章、作者、时间、查看/回复数；小说和文章详情有评论/楼中楼。源码包含发布和编辑文章路由。[论坛](https://n.novelia.cc/forum)、[路由](https://github.com/auto-novel/auto-novel/blob/main/web/src/router.ts)

- P0：帖子列表、正文、站内链接、教程、小说评论和回复阅读；链接可跳转 App 内相应书籍。
- P1：发帖、编辑自己的文章、评论/回复、内容预览、草稿恢复、锁帖和账号权限提示。
- P1：用户屏蔽、隐藏小说评论，复用服务器支持的规则；具体评论编辑/删除权限待登录验证。
- 增强：本地收藏帖子、论坛搜索、内容折叠。教程将部分论坛搜索和收藏功能归于站友脚本，不能假定存在网站原生搜索或收藏接口。
- 验收：正文和楼中楼正确呈现；草稿不因返回或网络失败丢失；重复点击不会重复发布；发帖成功后回到已发布内容。

### M14 设置、通知与帮助

**原站依据：页面；其中通知增强另行标注。** 原站支持主题、目录行为、评论显示、收藏排序、分页方式、翻译按钮显示、任务完成语音提醒、搜索历史清理、用户黑名单导入/导出和阅读内容简繁转换。[设置](https://n.novelia.cc/setting)

- P0：主题/跟随系统、阅读偏好、列表展示、搜索历史、缓存与帮助教程。
- P1：对齐目录、评论、收藏和工作区设置；黑名单编辑、导入/导出；安全导出不含密钥的普通配置。
- 增强：下载/翻译完成通知、追更检查、网络与电量条件、存储统计和故障诊断。
- 增强：更新提醒默认通过允许范围内的定期检查实现；没有验证服务器推送接口，不承诺实时更新或跨设备通知。
- 验收：关闭通知不影响下载/翻译结果保存；拒绝系统权限后仍能使用基本功能；数据清理的对象、大小和范围清楚。

### 可选：管理员能力

公开路由中存在用户管理、操作历史和网络目录合并历史。当前没有管理员会话，也未探索其操作细节。面向普通读者与翻译贡献者的版本可先保留权限控制下的网页入口；若后续明确需要管理员 App，再单独规划用户处置、资源维护与审计功能。[路由源码](https://github.com/auto-novel/auto-novel/blob/main/web/src/router.ts)

## 5. 关键流程

| 流程 | 完整链路 | 需要处理的异常 |
| --- | --- | --- |
| 找书阅读 | 发现/源站分享 → 搜索结果 → 详情 → 目录 → 阅读 → 书架继续阅读 | 链接不支持、内容未收录、译文缺失、网络失败 |
| 收藏追更 | 登录 → 收藏 → 分组 → 检查更新 → 新章节 → 阅读历史 | 会话失效、同步冲突、章节增删、未读状态变化 |
| 文库阅读 | 系列详情 → 登录 → 选择卷与译文 → 下载 → 加入本地书架 → 阅读 | 未完成翻译、无权限、空间不足、文件损坏 |
| 翻译贡献 | 详情/本地文件 → 引擎和范围 → 检查术语 → 排队 → 执行 → 回传或本地保存 → 阅读 | 限流、网络切换、进程中断、返回格式错误、回传拒绝 |
| 修正术语 | 打开术语表 → 编辑和预览 → 提交 → 识别过期译文 → 重翻 → 验证新译文 | 权限不足、版本冲突、任务仍在使用旧术语 |
| 社区反馈 | 书籍/教程 → 文章或评论 → 编辑与预览 → 发布 → 查看回复 | 锁帖、账号限制、草稿中断、重复提交 |

## 6. 推荐实现边界

建议以 Kotlin + Jetpack Compose 实现原生书架、发现、阅读器、下载和任务管理。Compose 是 Android 官方推荐的原生界面工具，适合这一类只面向安卓且依赖系统文件、通知和阅读交互的产品。[Android Compose](https://developer.android.com/compose)

| 能力 | 建议实现 | 接入前必须验证 |
| --- | --- | --- |
| 列表、详情、章节、收藏 | 原生页面加独立站点接口适配层 | 字段结构、鉴权、分页、速率限制、错误码与缓存语义 |
| EPUB/TXT/SRT | 本地文件与阅读/转换组件 | 文件格式、插图、字符编码、时间轴、损坏文件处理 |
| 登录/注册/找回密码 | 优先衔接现有统一认证 | 官方支持的回调方式、会话保持及原生请求鉴权 |
| 普通网页与教程 | App 内兼容页面或系统浏览器 | 站内链接路由、附件、返回行为 |
| 有道和浏览器爬虫 | 单独建立浏览器扩展兼容方案验证 | 原站扩展所需 API、书源登录/验证、翻译和回传校验 |
| GPT/Sakura | 原生任务调度与引擎适配；必要时保留现有工作区作为过渡 | 翻译算法/分块规则、站点接收流程、模型限制和失败恢复 |

GeckoView 官方提供 WebExtensions 运行和原生消息能力，因此可作为扩展兼容实验的候选；它是否完整支持本站扩展，仍需实际安装与业务测试，不能从“支持扩展”直接推导为“本站扩展全部可用”。一般网页容器也不能自动解决扩展依赖。[Mozilla GeckoView 文档](https://firefox-source-docs.mozilla.org/mobile/android/geckoview/consumer/web-extensions.html)

安卓后台执行存在系统约束。对于相应目标版本和服务类型，前台服务也有运行时长限制，因此方案应以“保存进度、可恢复、明确提示”为保障，不能承诺无限期后台挂机。长期云端运行需要单独的执行服务，未纳入原站现成功能。[Android 前台服务时限](https://developer.android.com/develop/background-work/services/fgs/timeout)

原站代码公开，且项目自身使用后端 API；这为功能核对提供条件，但不代表接口已经成为稳定的第三方公共契约。后续实现应优先确认站方支持的调用方式与兼容策略。[项目仓库](https://github.com/auto-novel/auto-novel)、[贡献指南](https://github.com/auto-novel/auto-novel/blob/main/CONTRIBUTING.md)

## 7. 数据与同步设计原则

以下是安卓方案设计，不代表原站已经支持所有同步对象。

| 数据对象 | App 内职责 | 与网站的关系 |
| --- | --- | --- |
| 书籍身份 | 网络小说按书源与书号识别，文库按系列与卷识别，本地按文件身份识别 | 避免用中文译名作为唯一键 |
| 章节及译文 | 原文与各引擎译文分别记录，保留可用性和版本 | 以实际章节状态判断完整性，不只看总数字 |
| 阅读位置 | 章节标识、段落锚点、必要的偏移、更新时间 | 云端能同步到哪一级需验证，其余本地保存 |
| 收藏夹 | 云端已支持对象与本地分组分别存储 | 不把本地文件自动变为服务器上传文件 |
| 翻译任务 | 任务来源、参数、术语版本、分块、重试和回传状态 | 默认本机任务；跨设备任务同步是另外的功能 |
| 下载与缓存 | 文件版本、格式、译文参数、路径和完整状态 | 区分文件下载、阅读缓存、原始本地文件 |
| 个人增强状态 | 书签、笔记、个人屏蔽、已读分类、提醒偏好 | 没有现成接口的部分先本地保存 |

## 8. 建议开发顺序

| 阶段 | 工作内容 | 退出条件 |
| --- | --- | --- |
| S0 接入验证 | 登录、公开内容 API、云收藏/阅读历史、文库下载、扩展依赖、翻译回传与后台恢复的小规模验证 | 每项都有可运行样例，或明确降级方式、受限范围和后续处理计划 |
| S1 阅读版 | 完成 M01–M09、M13–M14 的 P0 项：搜索、排行、详情、书架、阅读器、本地 EPUB/TXT、下载、社区浏览 | 找书→收藏→阅读→下载→离线继续的主流程在真机通过 |
| S2 翻译协作版 | M10–M12 以及文库贡献、元数据编辑、论坛发布等 P1 项 | 翻译与贡献流程可执行、可恢复、可追踪，站点读写通过验证 |
| S3 体验增强 | TTS、追更提醒、笔记、更多本地筛选、批处理、平板布局及可选管理员功能 | 依据选定的增强项逐项验收 |

“覆盖绝大多数功能”以功能条目的验收结果衡量，不以页面能否打开衡量。对每个条目标记原生可用、兼容页完整可用、仅外部跳转、受限或未实现；仅外部跳转不能算完整覆盖。

当前不宜给出固定工期，主要不确定性集中于统一认证、扩展依赖和翻译回传。S0 完成后，可根据真实接口和兼容结果拆分开发任务并估算工作量。

## 9. 后续必须补齐的验证

| 待验证事项 | 原因 | 影响模块 |
| --- | --- | --- |
| 登录成功、会话续期、退出与注册恢复流程 | 本次只检查了表单，没有登录账号 | M01 |
| 网络/文库收藏写入及多收藏夹操作 | 游客请求返回 401 | M06 |
| 阅读历史与阅读位置同步粒度 | 已有登录后入口，服务端字段和冲突语义未验证 | M05、M06 |
| 文库卷列表、不同翻译状态的下载与本地阅读 | 目录要求登录，未下载真实卷文件 | M07、M09 |
| 有道、六类书源的导入/更新、扩展兼容 | 不同书源依赖不同浏览器能力 | M02、M04、M10 |
| GPT/BETA/Sakura 实际调用与译文回传 | 本次没有配置密钥或运行付费/共享任务 | M10 |
| 术语更新、过期判定与重翻结果 | 目前依据官方说明，尚未进行写入测试 | M11 |
| 文件上传与元数据/评论/帖子写权限 | 账号资格与服务端规则不同 | M04、M07、M13 |
| 排行实时数据 | 本次 Kakuyomu 默认条件为空 | M03 |
| 站点推送或更新检查接口 | 本次未发现或验证服务器推送功能 | M06、M14 |

这些事项属于进入开发阶段后的接入验证范围，不影响本次模块规划成立；相应功能在验证前保持“计划支持”，不描述成已可直接接入。
