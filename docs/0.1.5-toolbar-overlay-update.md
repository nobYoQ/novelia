# Novelia 0.1.5 阅读器工具栏修复报告

## 本次修复

### 1. 工具栏显隐不再触发分页变化

原先自动分页会从正文高度中扣除顶部和底部工具栏的高度。点击正文显示工具栏时，可容纳的文字行数减少，导致本页文字、总页数和分页位置发生变化；工具栏动画过程中还可能反复触发重排。

现在正文与工具栏分别布局：正文使用固定的屏幕区域和边距，工具栏在其上覆盖显示。显示、收起工具栏，展开搜索栏，显示或隐藏翻页按钮，都不会改变正文可用空间。只有字号、行距、内容宽度、屏幕尺寸等实际影响正文排版的变化才需要重新分页。

| 操作 | 自动分页 | 连续滚动 |
| --- | --- | --- |
| 显示或收起工具栏 | 本页文字、页码及文字位置不变 | 正文坐标及滚动位置不变 |
| 展开或收起搜索栏 | 覆盖正文，不压缩页面 | 覆盖正文，不推移正文 |
| 调整工具栏透明度 | 只改变背景绘制 | 只改变背景绘制 |
| 显示或隐藏翻页按钮 | 不改变页容量及总页数 | 不改变正文留白及滚动位置 |

连续滚动的「上一屏／下一屏」按固定正文视口的约 85% 移动，保留相邻屏幕间的部分文字重叠。步长不再随工具栏的显示状态改变。自动分页的「上一页／下一页」仍按整页切换。

### 2. 可调整的半透明工具栏

- 设置入口：阅读器 → 阅读设置 → 阅读偏好 → 工具栏透明度；全局入口为「我的 → 阅读与外观 → 默认阅读偏好 → 工具栏透明度」。
- 默认透明度为 **25%**，即背景保留 75% 不透明度。
- 调整范围为 **0%–100%**：0% 为背景不透明，100% 为背景完全透明。
- 顶部工具栏、展开的搜索区域、底部工具栏与翻页按钮区域采用同一透明度。
- 仅调整工具栏背景，文字和图标保持原有颜色及可用／禁用状态；工具栏背景沿用当前阅读主题。
- 工具栏覆盖区域中的操作仍由工具栏接收，背景透明并不意味着点击穿透到正文。
- 可使用全局默认设置，也可开启「仅应用于这本书」保存单书透明度。关闭单书设置后恢复使用全局值。
- 透明度随阅读偏好持久化，并随现有设置备份导出；旧设置没有此字段时自动采用 25%。电子纸模式开关及分页模式切换保留透明度选择。

工具栏显示时会覆盖页面边缘的文字，点击正文收起后即可阅读完整页面。启用「显示翻页按钮」时，按钮仍按该偏好保留显示；可在阅读偏好中关闭它们。

升级后首次打开自动分页章节时，会按新的固定正文空间计算页数，并定位到原阅读位置所在页。因此旧包与新包的页数可能不同；之后显示或收起工具栏不会再次改变页容量。

### 3. 动态效果与电子纸模式

工具栏继续遵循「减少动态效果」及电子纸模式的动画规则：普通模式保留显隐过渡，减少动态效果或电子纸模式下直接显示／隐藏。动画仅影响覆盖层，正文布局不随动画变化。

## 本包同时包含的 0.1.5 更新

- 电子纸阅读模式、自动分页、长段落跨页、物理按键及手势翻页。
- 「连续滚动／自动分页」切换；滚动翻页和左右翻页归入自动分页的子选项。
- 恢复「显示翻页按钮」，并根据分页模式提供上一屏／下一屏或上一页／下一页。
- 黑白作为阅读主题中的独立选项，与其他主题互斥。
- 电子纸模式保存开启前状态，关闭时恢复，再次开启沿用上次电子纸设置。
- 云端多个收藏夹的「全部收藏」及网络收藏的搜索、书源、类型、分级、译文与排序筛选。
- 筛选区滚动折叠及展开动画，受减少动态效果管理；开关位于「阅读与外观」。
