# Novelia Android 设计约定

首版采用 Google Material 3 原生组件与交互语义。主色延续原站的绿色，明暗模式分别配色，不用滤镜反转。

| 项目 | 约定 |
| --- | --- |
| 浅色主色 | `#006C4C`，按钮文字白色 |
| 深色主色 | `#8FD6B4`，按钮文字 `#003825` |
| 浅色背景 | `#F7FAF5` |
| 深色背景 | `#101512` |
| 主色容器 | 浅色 `#ADF2CF`，深色 `#005137` |
| 间距 | 4/8 dp 基础节奏；页面主边距 20 dp；阅读器 24 dp |
| 点击目标 | Material 默认 48 dp 最小交互目标，图标均提供文字说明 |
| 字体 | 系统 Sans/CJK 字体，正文 16 sp，默认阅读字号 19 sp，遵循字体缩放 |
| 动效 | 页面渐入与短距离滑入约 220 ms；操作使用 Material 涟漪；可关闭页面动效 |
| 响应式 | 手机底部四项导航；宽度 600 dp 起使用导航栏侧轨；阅读正文可限制宽度 |

卡片、输入框、筛选 Chip、底部 Sheet、菜单和确认对话框使用 Material 3。常规页面只在加载中显示循环进度。按用户要求，「我的」页阅读搭子允许小幅左右摆动，每轮间歇休息；仅在卡片可见且应用处于前台时播放，并遵循应用的「减少动态效果」与系统动画时长设置。阅读器独立布局，纸张/亮色/深色主题具有各自的文字和系统栏对比度。

章节与长列表使用 LazyColumn，空结果、加载、无权限与网络失败具有独立呈现。删除云端收藏夹、文章、评论和清理缓存等操作提供明确对象说明。

缺少封面或封面加载失败时，以本地小绿贴纸、柔和渐变和书名组成默认封面，按作品标识固定分配表情。实际文库和 EPUB 封面优先显示。

个人卡片只显示可互动贴纸，不附加陪伴标语。下载和导入完成、空结果、网络失败、朗读定时结束及关于页彩蛋使用短暂贴纸反馈；遵循减少动态效果设置，结束后静止。设置中的「减少动态效果」只保留标题与开关。

阅读插图长按进入独立全屏查看器，支持 1～5 倍缩放、双指手势、拖动和双击还原。图片与正文位置保持独立；提供关闭、放大、缩小、还原按钮，以及加载失败重试。
